# Grammaire du HSK 5 : 42 fiches à relire

Source : liste officielle de grammaire du nouvel HSK (HSK 考试大纲, CLEC, programme 2025), niveau 5. Les 68 points officiels du niveau sont regroupés en 42 fiches rédigées pour l'appli ; chaque fiche indique les points qu'elle couvre.

Explications, exemples et questions : proposés par Claude, **à faire relire par un natif**. Contrôles automatiques : chaque phrase n'emploie que des mots officiels des niveaux 1 à 5 ; pinyin comparé au dictionnaire.

Pour valider : dis « grammaire HSK 5 OK », ou indique les fiches à corriger.

## 1. Suffixe 头, pronoms 彼此, 如此, 本

**Structure :** nom / verbe + 头 · 彼此 · 如此 · 本 + nom

头 forme des noms : 石头 (pierre), 木头 (bois), et après un verbe, « ce qui vaut la peine de » : 看头 (quelque chose à voir). 彼此 = l'un l'autre, mutuellement. 如此 = ainsi, tellement (écrit). 本 = ce…-ci, le présent… : 本人 (moi-même), 本店 (notre magasin).

**Exemples**

- 我们是老朋友了，彼此都很了解。 *Wǒmen shì lǎo péngyou le, bǐcǐ dōu hěn liǎojiě.* — Nous sommes de vieux amis, nous nous connaissons bien l'un l'autre.
- 事情既然如此，我们只好接受。 *Shìqing jìrán rúcǐ, wǒmen zhǐhǎo jiēshòu.* — Puisque les choses sont ainsi, nous n'avons plus qu'à accepter.

**Questions** (bonne réponse en gras)

- 这块___很重。 (Cette pierre est très lourde.) → **石头** / 石子头 / 头石
- ___店今天有优惠。 (Aujourd'hui, notre magasin fait une promotion.) → **本** / 如此 / 彼此

<sub>Points officiels : suffixe 头 · 彼此、如此、本</sub>

## 2. Classificateurs du niveau 5

**Structure :** nombre + 朵 / 颗 / 支 / 根 / 群 / 批 / 束… + nom · 看 + 一眼

朵 : fleurs, nuages ; 颗 : petits objets ronds (星, 心) ; 支 : objets fins (笔), chansons, équipes ; 根 : objets longs (筷子) ; 群 : groupes ; 批 : lots ; 束 : bouquets ; 副 : paires (眼镜) ; 架 : avions, machines ; 匹 : chevaux ; 届 : sessions, promotions ; 册 : volumes ; 集 : épisodes ; 行 : lignes ; 周 : semaines, tours. Pour les actions : 看了一眼 (jeter un coup d'œil).

**Exemples**

- 他送了我一束花。 *Tā sòngle wǒ yí shù huā.* — Il m'a offert un bouquet de fleurs.
- 天上有一朵白云。 *Tiān shang yǒu yì duǒ bái yún.* — Il y a un nuage blanc dans le ciel.

**Questions** (bonne réponse en gras)

- 他看了我一___，没说话。 (Il m'a jeté un coup d'œil sans rien dire.) → **眼** / 本 / 遍
- 我昨天看了三___电视剧。 (Hier, j'ai regardé trois épisodes de la série.) → **集** / 本 / 架

<sub>Points officiels : classificateurs 册、朵、届、颗、匹、行、架、群、支、根、批、束、副、集、周 · classificateur verbal 眼</sub>

## 3. Trop, assez, extrêmement : 过于, 相当, 格外, 极其

**Structure :** 过于 / 相当 / 较 / 格外 / 极其 + adjectif · adjectif + 得不得了

过于 = trop, excessivement (écrit) ; 相当 = assez, considérablement ; 较 = relativement (écrit, comme 比较) ; 格外 = particulièrement, plus que d'habitude ; 极其 = extrêmement (écrit) ; 可 = vraiment (oral) : 这孩子可聪明了. Après l'adjectif, 得不得了 = au plus haut point : 高兴得不得了. 不得了 seul = terrible, grave : 不得了了 !

**Exemples**

- 今天的天气格外好。 *Jīntiān de tiānqì géwài hǎo.* — Il fait particulièrement beau aujourd'hui.
- 听到这个消息，他高兴得不得了。 *Tīngdào zhège xiāoxi, tā gāoxìng de bùdéliǎo.* — En apprenant la nouvelle, il était fou de joie.

**Questions** (bonne réponse en gras)

- 这个问题___复杂，我们需要更多时间。 (Ce problème est assez complexe, il nous faut plus de temps.) → **相当** / 格外的 / 过于的
- 你不要___担心，事情会好起来的。 (Ne t'inquiète pas trop, ça va s'arranger.) → **过于** / 极其的 / 相当的

<sub>Points officiels : degré 过于、相当、较1、可2、格外、极其 · complément de degré 得不得了 · 不得了</sub>

## 4. Autrefois, depuis longtemps, toujours : 曾经, 早已, 始终

**Structure :** 曾经 / 早已 / 始终 / 时刻 / 即将 + verbe

曾经 = autrefois, avoir déjà (souvent avec 过) ; 早已 = depuis longtemps déjà ; 始终 = du début à la fin, toujours ; 时刻 = à chaque instant ; 即将 = être sur le point de (écrit).

**Exemples**

- 我曾经在北京住过两年。 *Wǒ céngjīng zài Běijīng zhùguo liǎng nián.* — J'ai vécu deux ans à Pékin autrefois.
- 比赛即将开始。 *Bǐsài jíjiāng kāishǐ.* — Le match va bientôt commencer.

**Questions** (bonne réponse en gras)

- 他___没有告诉我原因。 (Il ne m'a jamais dit pourquoi, du début à la fin.) → **始终** / 即将 / 曾经的
- 我到的时候，他们___走了。 (Quand je suis arrivé, ils étaient partis depuis longtemps.) → **早已** / 即将 / 时刻

<sub>Points officiels : temps 时刻、曾经、立刻、连忙、始终、早已、即将、急忙、渐渐、尽快、早晚</sub>

## 5. Aussitôt, en hâte, peu à peu

**Structure :** 立刻 / 连忙 / 急忙 / 尽快 / 渐渐 / 早晚 + verbe

立刻 = immédiatement ; 连忙 et 急忙 = en hâte (pour une réaction déjà passée) ; 尽快 = le plus vite possible ; 渐渐 = peu à peu ; 早晚 = tôt ou tard.

**Exemples**

- 看到老师进来，学生们连忙站了起来。 *Kàndào lǎoshī jìnlái, xuéshengmen liánmáng zhànle qǐlái.* — En voyant le professeur entrer, les élèves se sont levés précipitamment.
- 天渐渐黑了。 *Tiān jiànjiàn hēi le.* — La nuit tombe peu à peu.

**Questions** (bonne réponse en gras)

- 请你___回复我。 (Réponds-moi le plus vite possible, s'il te plaît.) → **尽快** / 连忙 / 渐渐
- 这件事你___会知道的。 (Tôt ou tard, tu l'apprendras.) → **早晚** / 急忙 / 立刻的

<sub>Points officiels : temps 时刻、曾经、立刻、连忙、始终、早已、即将、急忙、渐渐、尽快、早晚</sub>

## 6. Habituellement, toujours, soi-même

**Structure :** 通常 / 时常 / 老是 + verbe · 尽量 + verbe · 亲自 + verbe

通常 = habituellement ; 时常 = souvent ; 老是 = toujours (oral, souvent agacé). 尽量 = autant que possible ; 亲自 = en personne, soi-même.

**Exemples**

- 我通常七点起床。 *Wǒ tōngcháng qī diǎn qǐchuáng.* — Je me lève habituellement à sept heures.
- 经理亲自来机场接我们。 *Jīnglǐ qīnzì lái jīchǎng jiē wǒmen.* — Le directeur est venu en personne nous chercher à l'aéroport.

**Questions** (bonne réponse en gras)

- 你怎么___忘带钥匙？ (Pourquoi oublies-tu toujours tes clés ?) → **老是** / 通常的 / 亲自
- 我会___早点儿到。 (J'essaierai d'arriver un peu en avance.) → **尽量** / 亲自 / 时常的

<sub>Points officiels : fréquence 老是、通常、时常 · manière 尽量、亲自</sub>

## 7. Alors, dès que : 便, 一旦

**Structure :** …，便… · 一旦…，就…

便 = alors, aussitôt : c'est le 就 de la langue écrite. 一旦…，就… = une fois que, dès que (souvent pour un risque ou un changement décisif).

**Exemples**

- 他吃完饭便出去了。 *Tā chīwán fàn biàn chūqù le.* — Sitôt le repas terminé, il est sorti.
- 一旦做了决定，就不要后悔。 *Yídàn zuòle juédìng, jiù búyào hòuhuǐ.* — Une fois la décision prise, il ne faut pas regretter.

**Questions** (bonne réponse en gras)

- ___生病了，就要马上去医院。 (Dès qu'on tombe malade, il faut aller à l'hôpital.) → **一旦** / 一边 / 一起
- 他到了北京，___给家里打了电话。 (Arrivé à Pékin, il a aussitôt appelé chez lui.) → **便** / 从 / 却

<sub>Points officiels : liaison 便、一旦 · ……，便…… · 一旦……，就……</sub>

## 8. On dirait que : 似乎, 仿佛, 似的

**Structure :** 似乎 / 仿佛 + phrase · 像 / 好像…似的

似乎 = il semble que ; 仿佛 = comme si (plus littéraire). 似的 termine une comparaison : 像…似的 (comme…), 好像…似的 (comme si…).

**Exemples**

- 他似乎不太高兴。 *Tā sìhū bú tài gāoxìng.* — Il semble un peu mécontent.
- 她高兴得像个孩子似的。 *Tā gāoxìng de xiàng gè háizi shìde.* — Elle était heureuse comme une enfant.

**Questions** (bonne réponse en gras)

- 他好像什么都知道___。 (On dirait qu'il sait tout.) → **似的** / 仿佛 / 似乎
- 这里很安静，___一个人也没有。 (C'est si calme ici, comme s'il n'y avait personne.) → **仿佛** / 似的 / 一旦

<sub>Points officiels : 似乎、仿佛 · 似的</sub>

## 9. Après tout, étonnamment, comme prévu : 毕竟, 居然, 果然

**Structure :** 毕竟 / 居然 / 果然 + verbe

毕竟 = après tout (rappelle un fait essentiel) : 他毕竟还是个孩子. 居然 = étonnamment, contre toute attente. 果然 = en effet, comme prévu.

**Exemples**

- 别生气了，他毕竟还是个孩子。 *Bié shēngqì le, tā bìjìng háishi gè háizi.* — Ne te fâche pas, après tout ce n'est qu'un enfant.
- 天气预报说今天有雨，果然下雨了。 *Tiānqì yùbào shuō jīntiān yǒu yǔ, guǒrán xià yǔ le.* — La météo annonçait de la pluie, et en effet il pleut.

**Questions** (bonne réponse en gras)

- 这么简单的题，他___做错了。 (Une question si simple, et il s'est trompé !) → **居然** / 刚好 / 毕竟
- 我猜他会迟到，他___迟到了。 (J'avais deviné qu'il serait en retard, et en effet il l'a été.) → **果然** / 尽快 / 毕竟

<sub>Points officiels : ton 毕竟、居然、果然</sub>

## 10. De toute façon, pas du tout, absolument

**Structure :** 反正 · 根本 + 不 / 没 · 绝对 · 的确

反正 = de toute façon (quoi qu'il arrive). 根本 + négation = pas du tout, absolument pas. 绝对 = absolument. 的确 = effectivement, vraiment.

**Exemples**

- 你去不去都行，反正我要去。 *Nǐ qù bu qù dōu xíng, fǎnzhèng wǒ yào qù.* — Que tu viennes ou non, moi j'y vais de toute façon.
- 我根本不认识他。 *Wǒ gēnběn bú rènshi tā.* — Je ne le connais pas du tout.

**Questions** (bonne réponse en gras)

- 这件事我___不知道。 (Je n'étais absolument pas au courant.) → **根本** / 早晚 / 的确的
- 这个办法___不错。 (Cette méthode est effectivement bonne.) → **的确** / 根本 / 尽快

<sub>Points officiels : ton 反正、根本、绝对、的确</sub>

## 11. Carrément, juste, vraiment : 简直, 刚好, 可

**Structure :** 简直 + exagération · 刚好 · 可 + adjectif + 了

简直 = carrément, tout simplement (souligne une exagération) : 简直不敢相信. 刚好 = juste, pile. 可 à l'oral = vraiment (可好了, c'est vraiment bien) ou « enfin » (你可来了 !).

**Exemples**

- 这里的风景美得简直像画一样。 *Zhèlǐ de fēngjǐng měi de jiǎnzhí xiàng huà yíyàng.* — Le paysage ici est si beau qu'on dirait un tableau.
- 你可来了，我们等了你半天！ *Nǐ kě lái le, wǒmen děngle nǐ bàntiān!* — Te voilà enfin, on t'attend depuis une éternité !

**Questions** (bonne réponse en gras)

- 我___不敢相信自己的眼睛。 (Je n'en croyais tout simplement pas mes yeux.) → **简直** / 刚好 / 可是
- 我到车站的时候，车___来了。 (Quand je suis arrivé à l'arrêt, le bus arrivait juste.) → **刚好** / 简直 / 可见

<sub>Points officiels : ton 简直、刚好、可3</sub>

## 12. Au contraire : 反而, 不但不…反而

**Structure :** …，反而… · 不但不 / 不但没有…，反而…

反而 = au contraire, contre toute attente (le résultat va à l'inverse de ce qu'on espérait). 不但不…，反而… = non seulement ne… pas…, mais au contraire….

**Exemples**

- 吃了药，他的病反而更重了。 *Chīle yào, tā de bìng fǎn'ér gèng zhòng le.* — Après avoir pris le médicament, il est au contraire plus malade.
- 他不但没生气，反而笑了。 *Tā búdàn méi shēngqì, fǎn'ér xiào le.* — Loin de se fâcher, il s'est mis à rire.

**Questions** (bonne réponse en gras)

- 雨不但没停，___越下越大了。 (La pluie, loin de s'arrêter, tombe de plus en plus fort.) → **反而** / 可见 / 于是
- 我想帮他，他___不高兴了。 (Je voulais l'aider, et au contraire il s'est fâché.) → **反而** / 尽量 / 刚好

<sub>Points officiels : ton 反而 · 不但不/不但没有……，反而……</sub>

## 13. Pour rien, profiter de l'occasion : 白, 不X白不X

**Structure :** 白 + verbe · 不 + X + 白 + 不 + X

白 devant un verbe = en vain, pour rien : 白跑了一趟 (se déplacer pour rien). 不X白不X = si on ne le fait pas, c'est perdu : profitons-en : 不吃白不吃 (c'est gratuit, autant en manger).

**Exemples**

- 他不在家，我白跑了一趟。 *Tā bú zài jiā, wǒ bái pǎole yí tàng.* — Il n'était pas chez lui, je me suis déplacé pour rien.
- 免费的，不吃白不吃。 *Miǎnfèi de, bù chī bái bù chī.* — C'est gratuit, autant en profiter.

**Questions** (bonne réponse en gras)

- 我等了他两个小时，他没来，我___等了。 (Je l'ai attendu deux heures, il n'est pas venu : j'ai attendu pour rien.) → **白** / 很 / 了
- 这么好的机会，不去___不去。 (Une si belle occasion, il serait bête de ne pas y aller.) → **白** / 也 / 就

<sub>Points officiels : ton 白 · 不X白不X</sub>

## 14. Depuis : 自从, （自）…以来

**Structure :** 自从 + moment / événement · （自）… + 以来

自从 = depuis (un moment passé), souvent suivi de 以后 ou 以来. （自）…以来 = depuis… jusqu'à maintenant : 今年以来, 自上个月以来.

**Exemples**

- 自从来了中国，我每天都说汉语。 *Zìcóng láile Zhōngguó, wǒ měi tiān dōu shuō Hànyǔ.* — Depuis que je suis en Chine, je parle chinois tous les jours.
- 今年以来，这里的物价上涨了很多。 *Jīnnián yǐlái, zhèlǐ de wùjià shàngzhǎngle hěn duō.* — Depuis le début de l'année, les prix ont beaucoup augmenté ici.

**Questions** (bonne réponse en gras)

- ___他结婚以后，我们就很少见面了。 (Depuis son mariage, nous nous voyons rarement.) → **自从** / 从来 / 自己
- 上个月___，天气一直很好。 (Depuis le mois dernier, il fait toujours beau.) → **以来** / 以后来 / 起来

<sub>Points officiels : 自从 · （自）……以来</sub>

## 15. Vers, le long de : 朝, 沿着

**Structure :** 朝 + direction + verbe · 沿（着） + chemin + verbe

朝 = vers, en direction de, face à : 朝前走, 朝我笑. 沿 ou 沿着 = le long de : 沿着河走.

**Exemples**

- 他朝我笑了笑。 *Tā cháo wǒ xiàole xiào.* — Il m'a souri.
- 我们沿着河边散步。 *Wǒmen yánzhe hébiān sànbù.* — Nous nous promenons le long de la rivière.

**Questions** (bonne réponse en gras)

- 你___这条路一直走，就到了。 (Suis cette route tout droit et tu y seras.) → **沿着** / 朝着的 / 自从
- 窗户___南开。 (La fenêtre donne au sud.) → **朝** / 沿 / 从而

<sub>Points officiels : 朝、沿（着）</sub>

## 16. À la place de, avec : 替, 同, 较

**Structure :** 替 + personne + verbe · 同 + personne + verbe · A 较 B + adjectif

替 = à la place de, pour (quelqu'un) : 替我谢谢他. 同 = avec, et (écrit, comme 跟 / 和) : 同朋友一起. 较 = comparé à (écrit, comme 比) : 今年较去年好.

**Exemples**

- 请替我向你父母问好。 *Qǐng tì wǒ xiàng nǐ fùmǔ wènhǎo.* — Salue tes parents de ma part, s'il te plaît.
- 今年的收入较去年有所增加。 *Jīnnián de shōurù jiào qùnián yǒusuǒ zēngjiā.* — Les revenus de cette année ont quelque peu augmenté par rapport à l'an dernier.

**Questions** (bonne réponse en gras)

- 我今天有事，你能___我去开会吗？ (J'ai un empêchement, peux-tu aller à la réunion à ma place ?) → **替** / 较 / 朝
- 他___我一起去了上海。 (Il est allé à Shanghai avec moi.) → **同** / 替 / 较

<sub>Points officiels : 替、同1、较2 · conjonctions 以及、同2</sub>

## 17. Grâce à, selon : 凭, 据, 依据, 从…来看

**Structure :** 凭 + moyen · 据 + source · 依据 + règle · 从… + 来看

凭 = grâce à, sur la base de : 凭自己的努力 ; 凭票入场 (entrée sur présentation du billet). 据 = selon (une source) : 据说, 据调查. 依据 = conformément à. 从…来看 = à en juger par.

**Exemples**

- 他凭自己的努力考上了大学。 *Tā píng zìjǐ de nǔlì kǎoshàngle dàxué.* — Il est entré à l'université grâce à ses propres efforts.
- 从现在的情况来看，比赛会推迟。 *Cóng xiànzài de qíngkuàng lái kàn, bǐsài huì tuīchí.* — À en juger par la situation actuelle, le match sera reporté.

**Questions** (bonne réponse en gras)

- ___调查，大部分人喜欢网上购物。 (D'après l'enquête, la plupart des gens aiment acheter en ligne.) → **据** / 替 / 朝
- 请___票入场。 (Entrée sur présentation du billet.) → **凭** / 同 / 较

<sub>Points officiels : 凭、据、依据 · 从……来看</sub>

## 18. Ainsi que, composé de : 以及, 由…组成

**Structure :** A、B 以及 C · 由… + 组成

以及 = ainsi que, et (écrit), souvent avant le dernier élément d'une liste. 由…组成 = être composé de : 这个队由五个人组成.

**Exemples**

- 会上讨论了时间、地点以及费用。 *Huì shang tǎolùnle shíjiān, dìdiǎn yǐjí fèiyong.* — La réunion a porté sur la date, le lieu ainsi que les frais.
- 我们小组由五个人组成。 *Wǒmen xiǎozǔ yóu wǔ gè rén zǔchéng.* — Notre groupe est composé de cinq personnes.

**Questions** (bonne réponse en gras)

- 这个家庭由父母和两个孩子___。 (Cette famille se compose des parents et de deux enfants.) → **组成** / 组织 / 成组
- 请带上身份证、照片___报名表。 (Apportez votre carte d'identité, une photo ainsi que le formulaire d'inscription.) → **以及** / 以来 / 以上

<sub>Points officiels : conjonctions 以及、同2 · 由……组成</sub>

## 19. Ainsi, on voit que, bref : 从而, 因而, 可见, 总之

**Structure :** …，从而… · …，因而… · …，可见… · 总之，…

从而 = permettant ainsi de (résultat voulu) ; 因而 = par conséquent ; 可见 = on voit donc que (conclusion tirée de faits) ; 总之 = bref, en un mot. Tous sont plutôt écrits.

**Exemples**

- 他每天都练习，从而提高了口语水平。 *Tā měi tiān dōu liànxí, cóng'ér tígāole kǒuyǔ shuǐpíng.* — Il s'entraîne tous les jours, ce qui lui a permis d'améliorer son oral.
- 他连这么简单的题都不会，可见他没有好好复习。 *Tā lián zhème jiǎndān de tí dōu bú huì, kějiàn tā méiyǒu hǎohǎo fùxí.* — Il ne sait même pas répondre à une question si simple : on voit bien qu'il n'a pas révisé.

**Questions** (bonne réponse en gras)

- 有的人喜欢，有的人不喜欢，___，大家看法不同。 (Certains aiment, d'autres non : bref, les avis divergent.) → **总之** / 假如 / 从而
- 天气突然变冷，___很多人感冒了。 (Le temps s'est brusquement refroidi, et par conséquent beaucoup de gens ont attrapé froid.) → **因而** / 总之 / 假如

<sub>Points officiels : conjonctions 从而、可见、假如、总之 · ……，因而…… · ……，可见……</sub>

## 20. Si, au cas où : 假如, 万一

**Structure :** 假如…，（就）… · 万一…，（就）…

假如 = si, supposons que (écrit). 万一 = au cas où, si par malheur (pour une éventualité peu probable et fâcheuse).

**Exemples**

- 假如我是你，我就会接受。 *Jiǎrú wǒ shì nǐ, wǒ jiù huì jiēshòu.* — Si j'étais toi, j'accepterais.
- 带上雨伞吧，万一下雨呢。 *Dàishang yǔsǎn ba, wànyī xià yǔ ne.* — Prends un parapluie, au cas où il pleuvrait.

**Questions** (bonne réponse en gras)

- ___你迷路了，就给我打电话。 (Si jamais tu te perds, appelle-moi.) → **万一** / 一旦的 / 总之
- ___明天不下雨，我们就去爬山。 (S'il ne pleut pas demain, nous irons en montagne.) → **假如** / 可见 / 从而

<sub>Points officiels : conjonctions 从而、可见、假如、总之 · 假如……，（就）…… · 万一……，（就）……</sub>

## 21. Sinon : 要不然, 不然

**Structure :** …，要不然 / 不然…

要不然 et 不然 = sinon, autrement (comme 否则, mais plus oral). 要不 peut aussi proposer une autre solution : 要不我们明天去吧 (et si on y allait demain ?).

**Exemples**

- 快走吧，要不然就迟到了。 *Kuài zǒu ba, yàoburán jiù chídào le.* — Dépêchons-nous, sinon on sera en retard.
- 你得多穿点儿，不然会感冒的。 *Nǐ děi duō chuān diǎnr, bùrán huì gǎnmào de.* — Tu dois te couvrir davantage, sinon tu vas attraper froid.

**Questions** (bonne réponse en gras)

- 我们得早点儿出发，___会赶不上飞机。 (Il faut partir tôt, sinon nous allons rater l'avion.) → **要不然** / 要是 / 可见
- 今天太晚了，___我们明天再去吧。 (Il est trop tard aujourd'hui, et si on y allait plutôt demain ?) → **要不** / 不然的 / 可见

<sub>Points officiels : ……，要不然/不然……</sub>

## 22. Même si : 哪怕…也, 再…也

**Structure :** 哪怕…，也… · 再 + adjectif / verbe + 也…

哪怕…也… = même si (hypothèse extrême, oral et écrit). 再…也… = aussi… que ce soit : 再忙也要吃饭 (aussi occupé qu'on soit, il faut manger).

**Exemples**

- 哪怕下雨，我们也要去。 *Nǎpà xià yǔ, wǒmen yě yào qù.* — Même s'il pleut, nous irons.
- 再忙也要注意身体。 *Zài máng yě yào zhùyì shēntǐ.* — Aussi occupé que tu sois, fais attention à ta santé.

**Questions** (bonne réponse en gras)

- ___只有一点儿希望，我们也不放弃。 (Même s'il ne reste qu'un petit espoir, nous n'abandonnons pas.) → **哪怕** / 既然 / 因为
- 这个问题再难，我___要把它解决。 (Aussi difficile que soit ce problème, je le résoudrai.) → **也** / 就 / 才

<sub>Points officiels : 哪怕……，也…… · 再……也……</sub>

## 23. Ou bien ? : 不是…，还是…

**Structure :** 不是…，还 / 还是…

不是 A，还是 B ? propose de vérifier une hypothèse ou de corriger : « n'est-ce pas plutôt… ? ». À l'affirmatif, 不是…，还… ajoute une précision : 他不是不会，还是不想 (ce n'est pas qu'il ne sait pas, c'est plutôt qu'il ne veut pas).

**Exemples**

- 他不是不会，还是不想做。 *Tā bú shì bú huì, háishi bù xiǎng zuò.* — Ce n'est pas qu'il ne sait pas, c'est plutôt qu'il n'a pas envie.
- 这不是你的错，还是我没说清楚。 *Zhè bú shì nǐ de cuò, háishi wǒ méi shuō qīngchu.* — Ce n'est pas ta faute, c'est plutôt moi qui ne me suis pas bien expliqué.

**Questions** (bonne réponse en gras)

- 不是我不帮你，___我真的没有时间。 (Ce n'est pas que je ne veux pas t'aider, c'est vraiment que je n'ai pas le temps.) → **还是** / 要不 / 可见
- 他___不知道，是不想说。 (Ce n'est pas qu'il ne sait pas, c'est qu'il ne veut pas le dire.) → **不是** / 没有 / 别

<sub>Points officiels : 不是……，还/还是……</sub>

## 24. C'est pour : 为的是

**Structure :** …，为的是…

为的是 introduit le but d'une action déjà mentionnée : « c'est pour… ».

**Exemples**

- 他每天早起，为的是锻炼身体。 *Tā měi tiān zǎo qǐ, wèi de shì duànliàn shēntǐ.* — Il se lève tôt tous les jours pour faire de l'exercice.
- 我学汉语，为的是去中国工作。 *Wǒ xué Hànyǔ, wèi de shì qù Zhōngguó gōngzuò.* — J'apprends le chinois pour aller travailler en Chine.

**Questions** (bonne réponse en gras)

- 她努力存钱，___给父母买房子。 (Elle économise dur pour acheter une maison à ses parents.) → **为的是** / 因为是 / 可见是
- 我早点儿出门，为的___不迟到。 (Je pars tôt pour ne pas être en retard.) → **是** / 了 / 就

<sub>Points officiels : ……，为的是……</sub>

## 25. Sans… pas de… : 没有…就没有, 不…不…

**Structure :** 没有 A 就没有 B · 不 A 不 B

没有 A 就没有 B = sans A, il n'y aurait pas B : 没有你的帮助，就没有我的今天. 不 A 不 B = tant qu'on ne fait pas A, on ne fait pas B : 不见不散 (on ne part pas tant qu'on ne s'est pas retrouvés).

**Exemples**

- 没有你的帮助，就没有我的今天。 *Méiyǒu nǐ de bāngzhù, jiù méiyǒu wǒ de jīntiān.* — Sans ton aide, je ne serais pas là où j'en suis aujourd'hui.
- 明天八点，我们不见不散！ *Míngtiān bā diǎn, wǒmen bú jiàn bú sàn!* — Demain à huit heures, on s'attend jusqu'à se retrouver !

**Questions** (bonne réponse en gras)

- 没有努力，___没有成功。 (Sans effort, pas de réussite.) → **就** / 才 / 也是
- 这件事很重要，不说___行。 (C'est très important, il faut absolument le dire.) → **不** / 没 / 别

<sub>Points officiels : 没有……就没有…… · 不……不……</sub>

## 26. Soit… soit : 或是…或是

**Structure :** 或是…，或是…

或是…或是… = soit…, soit… (écrit, comme 或者…或者).

**Exemples**

- 周末我或是在家看书，或是出去走走。 *Zhōumò wǒ huòshì zài jiā kàn shū, huòshì chūqù zǒuzou.* — Le week-end, soit je lis à la maison, soit je sors me promener.
- 你可以或是坐地铁，或是坐出租车。 *Nǐ kěyǐ huòshì zuò dìtiě, huòshì zuò chūzūchē.* — Tu peux prendre soit le métro, soit un taxi.

**Questions** (bonne réponse en gras)

- 报名可以在网上，___去学校办理。 (On peut s'inscrire en ligne, ou bien sur place à l'école.) → **或是** / 然而 / 因而
- 晚饭或是吃面条，___吃米饭。 (Pour le dîner, soit des nouilles, soit du riz.) → **或是** / 于是 / 可是

<sub>Points officiels : 或是……，或是……</sub>

## 27. Dans tous les sens : 看来看去, 想来想去

**Structure :** A来A去 · X来X去，都是 / 就是…

A来A去 décrit une action répétée en va-et-vient : 走来走去 (faire les cent pas). X来X去，都是 / 就是… : après avoir longtemps…, on en revient toujours à… : 想来想去，还是这个办法好.

**Exemples**

- 他在房间里走来走去。 *Tā zài fángjiān li zǒu lái zǒu qù.* — Il fait les cent pas dans la chambre.
- 我想来想去，还是觉得这个办法最好。 *Wǒ xiǎng lái xiǎng qù, háishi juéde zhège bànfǎ zuì hǎo.* — J'ai beau réfléchir, je trouve toujours que cette méthode est la meilleure.

**Questions** (bonne réponse en gras)

- 我看来看___，还是这件衣服最好看。 (J'ai tout regardé, et ce vêtement reste le plus joli.) → **去** / 来 / 过
- 说来说去，___是钱的问题。 (Au bout du compte, c'est toujours une question d'argent.) → **都** / 才 / 再

<sub>Points officiels : A来A去 · X来X去，都是/就是……</sub>

## 28. À force de…, autant faire : 说着说着, 闲着也是闲着

**Structure :** A着A着 · X着也是X着

A着A着 + changement : pendant qu'on faisait A, soudain… : 说着说着就哭了 (en parlant, il s'est mis à pleurer). X着也是X着 = puisqu'on est de toute façon en train de X, autant faire autre chose : 闲着也是闲着，我帮你吧.

**Exemples**

- 她说着说着就哭了。 *Tā shuōzhe shuōzhe jiù kū le.* — En parlant, elle s'est mise à pleurer.
- 闲着也是闲着，我来帮你吧。 *Xiánzhe yě shì xiánzhe, wǒ lái bāng nǐ ba.* — Je n'ai rien à faire de toute façon, je vais t'aider.

**Questions** (bonne réponse en gras)

- 孩子看着看___就睡着了。 (À force de regarder, l'enfant s'est endormi.) → **着** / 了 / 过
- 等着也是等___，我们先吃点儿东西吧。 (Puisqu'on attend de toute façon, mangeons un morceau.) → **着** / 了 / 过

<sub>Points officiels : A着A着 · X着也是X着</sub>

## 29. Sans fin, chacun de son côté : 没A没B, A的A，B的B

**Structure :** 没 + A + 没 + B · A 的 A，B 的 B

没A没B renforce un manque : 没完没了 (sans fin), 没大没小 (sans respect des aînés). A的A，B的B répartit les actions : 吃的吃，玩的玩 (certains mangent, d'autres jouent).

**Exemples**

- 他说起来没完没了。 *Tā shuō qǐlái méi wán méi liǎo.* — Quand il commence à parler, il n'en finit plus.
- 大家唱的唱，跳的跳，非常热闹。 *Dàjiā chàng de chàng, tiào de tiào, fēicháng rènao.* — Les uns chantent, les autres dansent : l'ambiance est très animée.

**Questions** (bonne réponse en gras)

- 这孩子跟爷爷说话没大没___。 (Cet enfant parle à son grand-père sans aucun respect.) → **小** / 大 / 少
- 周末公园里，跑步的跑步，跳舞的___。 (Le week-end au parc, les uns courent, les autres dansent.) → **跳舞** / 跑步 / 的跳舞

<sub>Points officiels : 没A没B · A的A，B的B</sub>

## 30. Aussitôt dit, aussitôt fait : 说A就A, 用不着

**Structure :** 说 + A + 就 + A · 用不着 + verbe

说A就A = faire aussitôt qu'on l'a dit, sans préavis : 说走就走 (partir sur un coup de tête). 用不着 = ce n'est pas la peine de (oral, comme 不用).

**Exemples**

- 他这个人说走就走。 *Tā zhège rén shuō zǒu jiù zǒu.* — Lui, il part sur un coup de tête.
- 这点儿小事，用不着麻烦你。 *Zhè diǎnr xiǎo shì, yòngbuzháo máfan nǐ.* — Pour une si petite chose, pas la peine de te déranger.

**Questions** (bonne réponse en gras)

- 夏天的雨说来___来。 (En été, la pluie arrive sans prévenir.) → **就** / 才 / 也
- 你___这么着急，时间还早。 (Pas la peine de te presser autant, il est encore tôt.) → **用不着** / 用得着的 / 不用着

<sub>Points officiels : 说A就A · 用不着</sub>

## 31. Ni l'un ni l'autre ne va : X也不是，Y也不是

**Structure :** X也不是，Y也不是 · X也X不得，Y也Y不得

Ces deux moules décrivent un embarras : aucune des deux solutions ne convient. 哭也不是，笑也不是 (ne savoir s'il faut rire ou pleurer). 说也说不得，骂也骂不得 (on ne peut ni lui parler franchement ni le gronder).

**Exemples**

- 听了他的话，我哭也不是，笑也不是。 *Tīngle tā de huà, wǒ kū yě bú shì, xiào yě bú shì.* — En l'entendant, je ne savais plus s'il fallait rire ou pleurer.
- 这孩子，说也说不得，打也打不得。 *Zhè háizi, shuō yě shuō bu dé, dǎ yě dǎ bu dé.* — Cet enfant, on ne peut ni le gronder ni le punir.

**Questions** (bonne réponse en gras)

- 他站在那儿，走也不是，留也不___。 (Il restait planté là, sans savoir s'il devait partir ou rester.) → **是** / 行 / 对
- 这件事说___说不得。 (Cette affaire, impossible d'en parler.) → **也** / 就 / 才

<sub>Points officiels : X也不是，Y也不是 · X也X不得，Y也Y不得</sub>

## 32. Expressions de l'oral : 真有你的, 不管怎样说

**Structure :** X是它，Y也是它 · 不管怎样说 · 真有你 / 他 / 她的

X是它，Y也是它 = c'est la même chose qui fait l'un et l'autre : 成功是它，失败也是它. 不管怎样说 = quoi qu'on en dise, en tout cas. 真有你的 ! = toi alors ! (admiration ou reproche amusé).

**Exemples**

- 不管怎样说，他是你的哥哥。 *Bùguǎn zěnyàng shuō, tā shì nǐ de gēge.* — Quoi qu'on en dise, c'est ton frère.
- 这么难的题你都做出来了，真有你的！ *Zhème nán de tí nǐ dōu zuò chūlái le, zhēn yǒu nǐ de!* — Tu as résolu un problème aussi difficile, chapeau !

**Questions** (bonne réponse en gras)

- 你一个人做了这么多菜？真有你___！ (Tu as préparé tous ces plats tout seul ? Chapeau !) → **的** / 了 / 吗
- ___怎样说，我们都应该试一试。 (Quoi qu'on en dise, il faut essayer.) → **不管** / 不但 / 不是

<sub>Points officiels : X是它，Y也是它 · 不管怎样说 · 真有你/他/她的</sub>

## 33. Quel… !, peu importe : X什么X, 什么X不X的

**Structure :** X什么X · 什么 + X + 不 + X + 的 · 动词 + 什么（就）是什么

X什么X rejette ce qu'on vient d'entendre : 贵什么贵 ! (cher, tu parles !). 什么X不X的 balaie une objection : 什么累不累的 (fatigué ou pas, peu importe). Verbe + 什么（就）是什么 = on prend ce qu'il y a : 有什么吃什么.

**Exemples**

- 好什么好？一点儿也不好。 *Hǎo shénme hǎo? Yìdiǎnr yě bù hǎo.* — Bien, tu parles ! Ce n'est pas bien du tout.
- 家里有什么就吃什么吧。 *Jiā li yǒu shénme jiù chī shénme ba.* — Mangeons ce qu'il y a à la maison.

**Questions** (bonne réponse en gras)

- 什么累不累___，快干活儿吧！ (Fatigué ou pas, peu importe, au travail !) → **的** / 了 / 吗
- 你想要什么就买___。 (Achète ce que tu veux.) → **什么** / 怎么样 / 怎么

<sub>Points officiels : X什么X · 什么X不X（的） · 动词 + 什么（就）是什么</sub>

## 34. Plusieurs compléments devant le verbe

**Structure :** moment + lieu + manière / avec qui + verbe

Quand plusieurs éléments précisent le verbe, l'ordre habituel est : moment, puis adverbes (都, 也…), puis lieu ou personne (在…, 跟…), puis manière (认真地…), et enfin le verbe : 他昨天在图书馆认真地看了一下午书.

**Exemples**

- 他昨天在图书馆认真地看了一下午书。 *Tā zuótiān zài túshūguǎn rènzhēn de kànle yí xiàwǔ shū.* — Hier, il a lu sérieusement tout l'après-midi à la bibliothèque.
- 我们明天一起在学校门口见面吧。 *Wǒmen míngtiān yìqǐ zài xuéxiào ménkǒu jiànmiàn ba.* — Retrouvons-nous ensemble demain à l'entrée de l'école.

**Questions** (bonne réponse en gras)

- 她___学习汉语。 (Elle étudie le chinois sérieusement chaque jour à la maison.) → **每天在家认真地** / 认真地在家每天 / 在家认真地每天
- 我们___去吧。 (Allons-y ensemble demain.) → **明天一起** / 一起明天的 / 的明天一起

<sub>Points officiels : compléments circonstanciels multiples</sub>

## 35. Ne pas devoir, ne pas pouvoir : 吃不得, 去不得

**Structure :** verbe + 得 / 不得

Verbe + 不得 = on ne doit pas, on ne peut pas (c'est dangereux ou interdit) : 这种蘑菇吃不得 (ces champignons ne se mangent pas). Verbe + 得 = c'est possible, permis.

**Exemples**

- 这种东西吃不得。 *Zhè zhǒng dōngxi chī bu dé.* — Ce genre de chose ne se mange pas.
- 那个地方很危险，去不得。 *Nàge dìfang hěn wēixiǎn, qù bu dé.* — Cet endroit est dangereux, il ne faut pas y aller.

**Questions** (bonne réponse en gras)

- 这件事急不___，要慢慢来。 (Il ne faut pas se précipiter, allons-y doucement.) → **得** / 了 / 着
- 这些话说___说不得？ (Peut-on dire ces choses-là ou non ?) → **得** / 了 / 过

<sub>Points officiels : complément potentiel 得 / 不得</sub>

## 36. Devenir, commencer, continuer : 下来, 起来, 过来

**Structure :** verbe / adjectif + 下来 / 下去 / 起来 / 过来 / 过去

Après un adjectif, les compléments de direction décrivent un changement d'état : 冷静下来 (se calmer), 天黑下来 (la nuit tombe), 暖和起来 (se réchauffer), 醒过来 (se réveiller, reprendre connaissance), 晕过去 (s'évanouir), 瘦下去 (continuer à maigrir).

**Exemples**

- 天气慢慢暖和起来了。 *Tiānqì mànmàn nuǎnhuo qǐlái le.* — Le temps se réchauffe peu à peu.
- 你先冷静下来，再慢慢说。 *Nǐ xiān lěngjìng xiàlái, zài mànmàn shuō.* — Calme-toi d'abord, puis explique doucement.

**Questions** (bonne réponse en gras)

- 他终于醒___了。 (Il a enfin repris connaissance.) → **过来** / 下去 / 上去
- 天渐渐黑___了。 (La nuit tombe peu à peu.) → **下来** / 起去 / 过去来

<sub>Points officiels : compléments de direction 3 (état)</sub>

## 37. Au point de… : 得 + phrase

**Structure :** verbe / adjectif + 得 + verbe · + phrase · + expression

Au niveau 5, ce qui suit 得 peut être un verbe, une petite phrase ou une expression figée, pour dire jusqu'où va l'état : 累得走不动了 (fatigué au point de ne plus pouvoir marcher), 笑得大家都看着他, 忙得不可开交 (débordé).

**Exemples**

- 他累得走不动了。 *Tā lèi de zǒu bu dòng le.* — Il est si fatigué qu'il ne peut plus marcher.
- 她高兴得跳了起来。 *Tā gāoxìng de tiàole qǐlái.* — Elle a sauté de joie.

**Questions** (bonne réponse en gras)

- 他急___满头大汗。 (Il était si inquiet qu'il en transpirait à grosses gouttes.) → **得** / 的 / 地
- 这个笑话让大家笑___说不出话来。 (Cette blague a fait tellement rire tout le monde qu'on ne pouvait plus parler.) → **得** / 地 / 了

<sub>Points officiels : complément d'état 2</sub>

## 38. Avoir, porter : 有着, 写有

**Structure :** sujet + 有着 + objet · sujet + verbe + 有 + objet

有着 = avoir, posséder (écrit, pour des choses abstraites) : 有着悠久的历史. Verbe + 有 indique ce qui est inscrit ou attaché sur quelque chose : 上面写有名字 (un nom y est écrit).

**Exemples**

- 这座城市有着悠久的历史。 *Zhè zuò chéngshì yǒuzhe yōujiǔ de lìshǐ.* — Cette ville a une longue histoire.
- 信封上写有他的名字。 *Xìnfēng shang xiěyǒu tā de míngzi.* — Son nom est écrit sur l'enveloppe.

**Questions** (bonne réponse en gras)

- 中国和法国___不同的文化。 (La Chine et la France ont des cultures différentes.) → **有着** / 有了着 / 着有
- 盒子上写___"小心"两个字。 (Il est écrit « Attention » sur la boîte.) → **有** / 着有 / 的

<sub>Points officiels : phrase en 有 3</sub>

## 39. 把 : 把…一 + verbe, 把 A 当作 B

**Structure :** 把 + objet + 一 + verbe · 把 + objet 1 + verbe + objet 2

把 + objet + 一 + verbe décrit un geste bref et soudain : 他把书一放就走了. 把 A + verbe + B : traiter A comme B ou transformer A en B : 把他当作朋友, 把汉字写成拼音.

**Exemples**

- 他把门一关，就走了。 *Tā bǎ mén yì guān, jiù zǒu le.* — Il a fermé la porte d'un coup et il est parti.
- 我一直把他当作我的好朋友。 *Wǒ yìzhí bǎ tā dàngzuò wǒ de hǎo péngyou.* — Je l'ai toujours considéré comme un bon ami.

**Questions** (bonne réponse en gras)

- 我一直把他___哥哥。 (Je l'ai toujours considéré comme un grand frère.) → **当作** / 作当 / 当着
- 他把手___挥，大家都安静了。 (D'un geste de la main, il a fait taire tout le monde.) → **一** / 了 / 着

## 40. Deux verbes liés par le sens

**Structure :** sujet + verbe 1 + verbe 2 (cause, opposition, condition)

Deux groupes verbaux peuvent se suivre sans mot de liaison, la relation se devinant au sens : cause (他有事不能来 : il a un empêchement, donc ne peut pas venir), opposition (我去了没见到他 : j'y suis allé mais ne l'ai pas vu), condition (你有问题找我 : si tu as un problème, viens me voir).

**Exemples**

- 他生病没来上课。 *Tā shēngbìng méi lái shàngkè.* — Il est malade, il n'est pas venu en cours.
- 我去了他家没见到他。 *Wǒ qùle tā jiā méi jiàndào tā.* — Je suis allé chez lui, mais je ne l'ai pas vu.

**Questions** (bonne réponse en gras)

- 你有问题___找我。 (Si tu as un problème, viens me voir.) → **就** / 把 / 却
- 他有事不___来了。 (Il a un empêchement, il ne peut pas venir.) → **能** / 要 / 会是

## 41. Plus âgé de trois ans : 他大我三岁

**Structure :** A + adjectif + B + écart

Sans 比, on peut placer directement l'adjectif entre les deux termes, suivi de l'écart : 他大我三岁 (il a trois ans de plus que moi), 我高他一点儿.

**Exemples**

- 哥哥大我三岁。 *Gēge dà wǒ sān suì.* — Mon frère a trois ans de plus que moi.
- 他高我半个头。 *Tā gāo wǒ bàn gè tóu.* — Il me dépasse d'une demi-tête.

**Questions** (bonne réponse en gras)

- 姐姐___我两岁。 (Ma sœur a deux ans de plus que moi.) → **大** / 比大 / 大比
- 我高他___。 (Je suis un peu plus grand que lui.) → **一点儿** / 很多的 / 非常

## 42. Passif à l'oral : 被…给

**Structure :** sujet + 被 / 叫 / 让 + auteur + 给 + verbe + complément

À l'oral, on ajoute souvent 给 juste avant le verbe d'une phrase passive, sans changer le sens : 我的钱包被小偷给偷了.

**Exemples**

- 我的蛋糕被弟弟给吃了。 *Wǒ de dàngāo bèi dìdi gěi chī le.* — Mon gâteau a été mangé par mon petit frère.
- 衣服让雨给打湿了。 *Yīfu ràng yǔ gěi dǎshī le.* — Les vêtements ont été trempés par la pluie.

**Questions** (bonne réponse en gras)

- 我的手机被人___拿走了。 (Quelqu'un m'a pris mon téléphone.) → **给** / 把 / 对
- 杯子叫猫给打___了。 (Le verre a été cassé par le chat.) → **破** / 着 / 过
