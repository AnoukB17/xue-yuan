# Grammaire du HSK 4 : 54 fiches à relire

Source : liste officielle de grammaire du nouvel HSK (HSK 考试大纲, CLEC, programme 2025), niveau 4. Les 85 points officiels du niveau sont regroupés en 54 fiches rédigées pour l'appli ; chaque fiche indique les points qu'elle couvre.

Explications, exemples et questions : proposés par Claude, **à faire relire par un natif**. Contrôles automatiques : chaque phrase n'emploie que des mots officiels des niveaux 1 à 4 ; pinyin comparé au dictionnaire.

Pour valider : dis « grammaire HSK 4 OK », ou indique les fiches à corriger.

## 1. Oser : 敢

**Structure :** 敢 / 不敢 + verbe

敢 = oser. 不敢 = ne pas oser. Comme les autres verbes modaux, il se place devant le verbe : 我不敢一个人去.

**Exemples**

- 我不敢一个人晚上出去。 *Wǒ bù gǎn yí gè rén wǎnshang chūqù.* — Je n'ose pas sortir seul le soir.
- 你敢跟老师说吗？ *Nǐ gǎn gēn lǎoshī shuō ma?* — Tu oses le dire au professeur ?

**Questions** (bonne réponse en gras)

- 他太小了，不___自己睡觉。 (Il est trop petit, il n'ose pas dormir seul.) → **敢** / 要 / 该
- 这么高，你___跳下去吗？ (C'est si haut, tu oses sauter ?) → **敢** / 一定 / 就

<sub>Points officiels : 敢</sub>

## 2. Chaque, n'importe quel : 各, 任何, 此

**Structure :** 各 + (classificateur) + nom · 任何 + nom + 都 · 此 (écrit)

各 = chaque, les différents : 各国, 各位 (formule polie : « chers… »), 各种 (toutes sortes de). 任何 = n'importe quel, souvent avec 都 ou dans une négation : 任何人都可以. 此 = ce, ceci, à l'écrit : 此外, 从此, 此时.

**Exemples**

- 各位朋友，大家好！ *Gèwèi péngyou, dàjiā hǎo!* — Chers amis, bonjour à tous !
- 任何问题都可以问我。 *Rènhé wèntí dōu kěyǐ wèn wǒ.* — Vous pouvez me poser n'importe quelle question.

**Questions** (bonne réponse en gras)

- 商店里有___东西。 (Le magasin a toutes sortes de choses.) → **各种** / 任何 / 每个
- ___人都不能进去。 (Personne ne peut entrer.) → **任何** / 各位 / 此

<sub>Points officiels : 各、各位、各种、任何、此</sub>

## 3. Classificateurs du niveau 4

**Structure :** nombre + 台 / 棵 / 幅 / 袋 / 打 · 一 + 脸 / 身 / 屋子 · verbe + 场 / 顿 / 趟

台 : machines (电脑, 电视) ; 棵 : arbres ; 幅 : tableaux ; 袋 : sacs ; 打 : douzaines. Un nom de partie du corps ou de lieu devient classificateur pour dire « plein de » : 一脸的汗, 一屋子人. Pour les actions : 场 (un match, une pluie, une maladie), 顿 (un repas, une réprimande), 趟 (un aller-retour). Un adjectif peut se glisser : 一大碗, 一小块.

**Exemples**

- 我家门口有两棵大树。 *Wǒ jiā ménkǒu yǒu liǎng kē dà shù.* — Il y a deux grands arbres devant chez moi.
- 我明天要去一趟北京。 *Wǒ míngtiān yào qù yí tàng Běijīng.* — Demain, je dois faire un aller-retour à Pékin.

**Questions** (bonne réponse en gras)

- 我买了一___新电脑。 (J'ai acheté un nouvel ordinateur.) → **台** / 棵 / 幅
- 我们一起吃一___饭吧。 (Allons manger un repas ensemble.) → **顿** / 场 / 趟

<sub>Points officiels : classificateurs 打、袋、棵、台、幅 · classificateurs empruntés 脸、手、盒、屋子、桌子 · classificateurs verbaux 场、顿、趟 · nombre + adjectif + classificateur</sub>

## 4. Très, surtout, un peu : 十分, 尤其, 稍微

**Structure :** 十分 / 更加 / 尤其 / 稍微 + adjectif · 多么…啊 · adjectif + 死了 / 得厉害

十分 = très, tout à fait ; 更加 = encore plus (soutenu) ; 尤其 = surtout, en particulier ; 稍 ou 稍微 = un peu, légèrement (souvent avec 一点儿 / 一下) ; 多么…啊 ! = comme c'est… ! Après l'adjectif ou un verbe de sentiment, 死了 et 得厉害 marquent un degré extrême (oral) : 累死了, 疼得厉害.

**Exemples**

- 我喜欢运动，尤其喜欢游泳。 *Wǒ xǐhuan yùndòng, yóuqí xǐhuan yóuyǒng.* — J'aime le sport, surtout la natation.
- 请你稍微等一下。 *Qǐng nǐ shāowēi děng yíxià.* — Attends un petit instant, s'il te plaît.

**Questions** (bonne réponse en gras)

- 今天热___了！ (Il fait une chaleur à mourir aujourd'hui !) → **死** / 厉害 / 十分
- 他的头疼得___。 (Il a terriblement mal à la tête.) → **厉害** / 死了了 / 十分

<sub>Points officiels : degré 十分、更加、稍、稍微、尤其、多么 · complément de degré 2 (死了、厉害)</sub>

## 5. En tout, seulement, au moins : 共, 光, 仅, 至少

**Structure :** 共 / 全 / 光 / 仅 / 仅仅 / 至少 + verbe ou quantité

共 = en tout (écrit, comme 一共) ; 全 = tout, entièrement ; 光 = seulement (oral) ; 仅 et 仅仅 = seulement (écrit) ; 至少 = au moins.

**Exemples**

- 我们班全是女生。 *Wǒmen bān quán shì nǚshēng.* — Notre classe n'a que des filles.
- 这本书至少要一百块。 *Zhè běn shū zhìshǎo yào yìbǎi kuài.* — Ce livre coûte au moins cent yuans.

**Questions** (bonne réponse en gras)

- 他___吃菜，不吃米饭。 (Il ne mange que les plats, pas le riz.) → **光** / 至少 / 全部
- 从这儿到机场___要一个小时。 (D'ici à l'aéroport, il faut au moins une heure.) → **至少** / 光 / 共同

<sub>Points officiels : portée 共、全、光、仅、仅仅、至少</sub>

## 6. À l'heure, jamais, soudain : 按时, 从来, 忽然

**Structure :** 按时 / 赶紧 / 赶快 / 忽然 / 本来 / 从来 + verbe

按时 = à l'heure prévue ; 赶紧 et 赶快 = vite, sans tarder ; 忽然 = soudain ; 本来 = au départ, à l'origine ; 从来 + 不 / 没 = jamais : 我从来不喝酒. 已 = déjà (écrit, comme 已经) ; 从 + 不 / 没 = jamais (écrit).

**Exemples**

- 他从来不迟到。 *Tā cónglái bù chídào.* — Il n'est jamais en retard.
- 我本来想去，后来没时间了。 *Wǒ běnlái xiǎng qù, hòulái méi shíjiān le.* — Au départ je voulais y aller, mais ensuite je n'ai plus eu le temps.

**Questions** (bonne réponse en gras)

- 下雨了，___回家吧！ (Il pleut, rentrons vite !) → **赶紧** / 从来 / 本来
- 你每天要___吃药。 (Tu dois prendre tes médicaments à l'heure tous les jours.) → **按时** / 忽然 / 从来

<sub>Points officiels : temps 按时、从来、赶紧、赶快、已、忽然、将、将要、从、本来</sub>

## 7. Futur écrit et 将 = 把

**Structure :** 将 / 将要 + verbe · 将 + objet + verbe

将 et 将要 = « va, allait » pour un futur, dans une langue écrite (journaux, annonces) : 会议将在明天举行. 将 sert aussi de préposition écrite, comme 把 : 请将门关好.

**Exemples**

- 火车将在十分钟后到站。 *Huǒchē jiāng zài shí fēnzhōng hòu dào zhàn.* — Le train arrivera en gare dans dix minutes.
- 请将手机关上。 *Qǐng jiāng shǒujī guānshang.* — Veuillez éteindre vos téléphones.

**Questions** (bonne réponse en gras)

- 比赛___在下午三点开始。 (Le match commencera à quinze heures.) → **将** / 从 / 对
- 请___这些东西放好。 (Veuillez ranger ces affaires.) → **将** / 被 / 对

<sub>Points officiels : temps 按时、从来、赶紧、赶快、已、忽然、将、将要、从、本来 · prépositions 将、由2、叫、让</sub>

## 8. Souvent, parfois, de nouveau

**Structure :** 往往 / 偶尔 / 老 / 重新 / 再次 + verbe

往往 = souvent, en général (constat d'une tendance) ; 偶尔 = de temps en temps ; 老 = toujours (oral, souvent agacé) ; 重新 = de nouveau, depuis le début ; 再次 = une nouvelle fois (écrit).

**Exemples**

- 这篇文章写得不好，我要重新写。 *Zhè piān wénzhāng xiě de bù hǎo, wǒ yào chóngxīn xiě.* — Cet article est mal écrit, je dois le réécrire.
- 我偶尔去看电影。 *Wǒ ǒu'ěr qù kàn diànyǐng.* — Je vais au cinéma de temps en temps.

**Questions** (bonne réponse en gras)

- 你怎么___迟到？ (Pourquoi es-tu toujours en retard ?) → **老** / 偶尔 / 重新
- 周末的时候，人___很多。 (Le week-end, il y a souvent beaucoup de monde.) → **往往** / 重新 / 故意

<sub>Points officiels : fréquence 重新、往往、偶尔、再次、老</sub>

## 9. Exprès, mutuellement : 故意, 互相

**Structure :** 故意 / 互相 / 相互 + verbe

故意 = exprès, volontairement. 互相 et 相互 (plus écrit) = l'un l'autre, mutuellement : 互相帮助.

**Exemples**

- 对不起，我不是故意的。 *Duìbuqǐ, wǒ bú shì gùyì de.* — Pardon, je ne l'ai pas fait exprès.
- 同学之间要互相帮助。 *Tóngxué zhī jiān yào hùxiāng bāngzhù.* — Entre camarades, il faut s'entraider.

**Questions** (bonne réponse en gras)

- 他___不回答我的问题。 (Il ne répond pas exprès à ma question.) → **故意** / 互相 / 重新
- 我们___认识一下吧。 (Faisons connaissance.) → **互相** / 故意 / 本来

<sub>Points officiels : manière 故意、互相、相互</sub>

## 10. Pourtant, mais : 却, 然而, 不过

**Structure :** sujet + 却 + verbe · …，然而 / 不过… · X是X，就是 / 不过…

却 = pourtant, se place APRÈS le sujet, devant le verbe : 他很累，却不想休息. 然而 = cependant (écrit) ; 不过 = mais, toutefois (plus doux que 但是). X是X，就是 / 不过… concède puis nuance : 好是好，就是太贵了 (c'est bien, mais trop cher).

**Exemples**

- 他很累，却不想休息。 *Tā hěn lèi, què bù xiǎng xiūxi.* — Il est très fatigué, pourtant il ne veut pas se reposer.
- 这件衣服好看是好看，就是太贵了。 *Zhè jiàn yīfu hǎokàn shì hǎokàn, jiùshì tài guì le.* — Ce vêtement est joli, c'est vrai, mais il est trop cher.

**Questions** (bonne réponse en gras)

- 大家都来了，他___没来。 (Tout le monde est venu, mais lui non.) → **却** / 于是 / 就
- 这个办法不错，___有点儿麻烦。 (Cette méthode n'est pas mauvaise, mais un peu compliquée.) → **不过** / 于是 / 因此

<sub>Points officiels : 却 · 不过 · conjonctions 而2、并且 · 尽管……，但是/可是…… ; ……，然而…… ; ……，不过…… ; ……X是X，就是/不过……</sub>

## 11. Peut-être, je crains que : 也许, 恐怕, 说不定

**Structure :** 也许 / 恐怕 / 说不定 + phrase

也许 = peut-être. 恐怕 = je crains que, probablement (pour une chose qu'on ne souhaite pas). 说不定 = peut-être bien, qui sait (oral).

**Exemples**

- 也许他已经回家了。 *Yěxǔ tā yǐjīng huí jiā le.* — Il est peut-être déjà rentré.
- 明天恐怕会下雨。 *Míngtiān kǒngpà huì xià yǔ.* — J'ai bien peur qu'il pleuve demain.

**Questions** (bonne réponse en gras)

- 现在去___来不及了。 (J'ai bien peur qu'il soit trop tard pour y aller maintenant.) → **恐怕** / 本来 / 故意
- 别着急，___他马上就到了。 (Ne t'inquiète pas, il va peut-être arriver d'une minute à l'autre.) → **说不定** / 从来 / 按时

<sub>Points officiels : 也许、恐怕 · 说不定</sub>

## 12. Étonnamment, au juste : 竟然, 究竟, 到底

**Structure :** 竟然 + verbe · 究竟 / 到底 + question

竟然 = contre toute attente, étonnamment. 究竟 et 到底 renforcent une question : « au juste, enfin ». 到底 veut aussi dire « finalement, après tout ».

**Exemples**

- 这么难的题，他竟然做对了。 *Zhème nán de tí, tā jìngrán zuòduì le.* — Une question si difficile, et il a trouvé la bonne réponse !
- 你到底去不去？ *Nǐ dàodǐ qù bu qù?* — Alors, tu y vas ou pas, au juste ?

**Questions** (bonne réponse en gras)

- 这件事___是谁做的？ (Qui a fait ça, au juste ?) → **究竟** / 竟然 / 确实
- 他学了一年，___说得这么好！ (Il n'étudie que depuis un an, et il parle si bien !) → **竟然** / 究竟 / 千万

<sub>Points officiels : ton 竟然、究竟、到底</sub>

## 13. Quand même pas… ? : 难道, questions rhétoriques

**Structure :** 难道…吗 ? · mot interrogatif dans une question rhétorique

难道…吗 ? exprime l'étonnement ou le reproche : 难道你不知道吗 ? (tu ne le savais quand même pas ?). Les mots interrogatifs peuvent aussi poser une fausse question : 谁不想去 ? (qui ne voudrait pas y aller ? = tout le monde veut), 我怎么知道 ? (comment le saurais-je ? = je ne sais pas).

**Exemples**

- 难道你不知道吗？ *Nándào nǐ bù zhīdào ma?* — Tu ne le savais quand même pas ?
- 这么好的机会，谁不想要？ *Zhème hǎo de jīhuì, shéi bù xiǎng yào?* — Une si belle occasion, qui n'en voudrait pas ?

**Questions** (bonne réponse en gras)

- ___你忘了今天是我的生日吗？ (Tu as quand même pas oublié que c'est mon anniversaire ?) → **难道** / 到底 / 确实
- 我又不是他，我___知道他在想什么？ (Je ne suis pas lui, comment saurais-je à quoi il pense ?) → **怎么** / 什么 / 为了

<sub>Points officiels : ton 难道 · question rhétorique 2 (难道, mots interrogatifs)</sub>

## 14. Surtout, vraiment, être obligé : 千万, 确实, 只好, 正好

**Structure :** 千万 + (别 / 要) + verbe · 确实 · 只好 · 正好

千万 = surtout, à tout prix (souvent avec 别 / 要) ; 确实 = effectivement, vraiment ; 只好 = n'avoir d'autre choix que de ; 正好 = juste à point, par chance.

**Exemples**

- 你千万别忘了！ *Nǐ qiānwàn bié wàng le!* — Surtout, n'oublie pas !
- 没有车了，我们只好走回去。 *Méiyǒu chē le, wǒmen zhǐhǎo zǒu huíqù.* — Il n'y a plus de bus, nous sommes obligés de rentrer à pied.

**Questions** (bonne réponse en gras)

- 你来得___，我们刚要吃饭。 (Tu tombes bien, nous allions passer à table.) → **正好** / 只好 / 千万
- 这个问题___很难。 (Cette question est effectivement difficile.) → **确实** / 千万 / 只好

<sub>Points officiels : ton 千万、确实、只好、正好</sub>

## 15. Presque : 差（一）点儿

**Structure :** 差（一）点儿 + verbe

差点儿 = faillir, presque : 我差点儿迟到了 (j'ai failli être en retard). Pour une chose qu'on ne souhaite pas, 差点儿 et 差点儿没 ont le même sens : la chose n'est pas arrivée.

**Exemples**

- 我差点儿忘了。 *Wǒ chàdiǎnr wàng le.* — J'ai failli oublier.
- 今天路上车很多，我差一点儿迟到。 *Jīntiān lù shang chē hěn duō, wǒ chà yìdiǎnr chídào.* — Il y avait beaucoup de voitures aujourd'hui, j'ai failli être en retard.

**Questions** (bonne réponse en gras)

- 刚才我___忘了带手机。 (Tout à l'heure, j'ai failli oublier mon téléphone.) → **差点儿** / 一点儿 / 有点儿
- 他跑得很快，___就赶上火车了。 (Il a couru très vite et a presque eu le train.) → **差点儿** / 一点儿 / 十分

<sub>Points officiels : ton 差（一）点儿</sub>

## 16. Nuances : 才, 就, 并, 还

**Structure :** 才 / 就 / 并 / 还 + verbe ou adjectif

才 insiste avec force : 我才不去呢 ! (je n'irai sûrement pas !). 就 marque une décision ou une affirmation : 我就要这个. 并 + 不 / 没 contredit ce qu'on pourrait croire : 他并不知道 (en réalité il ne savait pas). 还 = assez, plutôt (还不错 : pas mal du tout).

**Exemples**

- 这个问题并不难。 *Zhège wèntí bìng bù nán.* — Ce problème n'est pas si difficile que ça.
- 这家饭店的菜还不错。 *Zhè jiā fàndiàn de cài hái búcuò.* — Les plats de ce restaurant sont plutôt bons.

**Questions** (bonne réponse en gras)

- 我___不想去呢！ (Je n'ai vraiment pas envie d'y aller !) → **才** / 把 / 被
- 你说他很高兴，其实他___不高兴。 (Tu dis qu'il est content, en fait il ne l'est pas du tout.) → **并** / 把 / 对

<sub>Points officiels : ton 才4、就5、并1、还4</sub>

## 17. Depuis, quand, au fur et à mesure : 自, 当, 随着

**Structure :** 自 / 由 + point de départ · 当…的时候 · 随着 + changement · 等 + événement

自 et 由 = depuis, à partir de (écrit) : 自明天起, 由北京出发. 当…的时候 = au moment où. 随着 = au fur et à mesure de, avec : 随着时间的变化. 等 + événement = une fois que : 等他来了再说.

**Exemples**

- 当我到的时候，他已经走了。 *Dāng wǒ dào de shíhou, tā yǐjīng zǒu le.* — Quand je suis arrivé, il était déjà parti.
- 随着年龄的增长，他越来越安静了。 *Suízhe niánlíng de zēngzhǎng, tā yuè lái yuè ānjìng le.* — Avec l'âge, il est devenu de plus en plus calme.

**Questions** (bonne réponse en gras)

- ___你有时间了，我们再去吧。 (Une fois que tu auras du temps, nous irons.) → **等** / 当时 / 自
- 这趟火车___北京开往上海。 (Ce train part de Pékin pour Shanghai.) → **由** / 对 / 向

<sub>Points officiels : prépositions 自、当、由1、随着、等1</sub>

## 18. Parce que, c'est pourquoi : 由于, 因此

**Structure :** 由于…，（因此）… · 由 + responsable + verbe

由于 = en raison de, parce que (plus écrit que 因为) ; 因此 = c'est pourquoi, par conséquent. Avec 由于, on n'emploie pas 所以 mais 因此 ou rien. 由 + personne + verbe désigne qui est chargé de faire : 这件事由我负责.

**Exemples**

- 由于下大雨，比赛推迟了。 *Yóuyú xià dà yǔ, bǐsài tuīchí le.* — En raison d'une forte pluie, le match a été reporté.
- 这件事由我负责。 *Zhè jiàn shì yóu wǒ fùzé.* — C'est moi qui suis responsable de cette affaire.

**Questions** (bonne réponse en gras)

- 他工作很努力，___大家都很喜欢他。 (Il travaille dur, c'est pourquoi tout le monde l'apprécie.) → **因此** / 由于 / 不过
- ___天气不好，飞机晚点了。 (En raison du mauvais temps, l'avion est en retard.) → **由于** / 因此 / 于是

<sub>Points officiels : 由于1 · conjonctions 此外、另外、加上 · prépositions 将、由2、叫、让 · 因此、由于2 · （由于）……，因此……</sub>

## 19. Au sujet de, avec : 对于, 与

**Structure :** 对于 + sujet，… · A 与 B · 与 + personne + verbe

对于 = quant à, en ce qui concerne (introduit le sujet dont on parle). 与 = et, avec, à l'écrit (comme 和 / 跟) : 我与他见了面, 老师与学生.

**Exemples**

- 对于这个问题，大家的看法不一样。 *Duìyú zhège wèntí, dàjiā de kànfǎ bù yíyàng.* — Sur cette question, les avis divergent.
- 我与他是大学同学。 *Wǒ yǔ tā shì dàxué tóngxué.* — Lui et moi étions camarades à l'université.

**Questions** (bonne réponse en gras)

- ___我来说，这是一个好机会。 (Pour moi, c'est une bonne occasion.) → **对** / 与 / 把
- ___这件事，我没有意见。 (Au sujet de cette affaire, je n'ai pas d'objection.) → **对于** / 为了 / 随着

<sub>Points officiels : 对于、与1 · conjonctions 并2、而1、与2</sub>

## 20. En tant que, selon : 作为, 按照

**Structure :** 作为 + rôle，… · 按 / 按照 + règle + verbe

作为 = en tant que : 作为学生，… . 按 et 按照 = selon, conformément à (une règle, un plan, un horaire) : 按照老师说的做.

**Exemples**

- 作为老师，我应该帮助学生。 *Zuòwéi lǎoshī, wǒ yīnggāi bāngzhù xuésheng.* — En tant que professeur, je dois aider les élèves.
- 请按照说明书使用。 *Qǐng ànzhào shuōmíngshū shǐyòng.* — Veuillez utiliser l'appareil selon le mode d'emploi.

**Questions** (bonne réponse en gras)

- 我们___时间表上课。 (Nous suivons les cours selon l'emploi du temps.) → **按** / 作为 / 随着
- ___一个中国人，我很爱吃饺子。 (En tant que Chinois, j'adore les raviolis.) → **作为** / 按照 / 对于

<sub>Points officiels : 作为、按、按照</sub>

## 21. Et, mais : 而, 并且

**Structure :** A 而 B · …，而… · …，并且…

而 relie deux adjectifs ou deux idées (écrit) : 简单而有效 (simple et efficace) ; il marque aussi une opposition : 他喜欢运动，而我喜欢看书. 并 et 并且 = et de plus, et aussi : 他同意了，并且马上开始工作.

**Exemples**

- 他喜欢运动，而我喜欢看书。 *Tā xǐhuan yùndòng, ér wǒ xǐhuan kàn shū.* — Lui aime le sport, alors que moi j'aime lire.
- 他同意了，并且马上开始工作。 *Tā tóngyì le, bìngqiě mǎshàng kāishǐ gōngzuò.* — Il a accepté et s'est aussitôt mis au travail.

**Questions** (bonne réponse en gras)

- 这个办法简单___有效。 (Cette méthode est simple et efficace.) → **而** / 于是 / 才
- 她会说汉语，___说得很好。 (Elle parle chinois, et elle le parle très bien.) → **并且** / 于是 / 否则

<sub>Points officiels : conjonctions 并2、而1、与2 · conjonctions 而2、并且 · 不仅/不光……，还/而且…… ; ……，并且……</sub>

## 22. De plus, en outre : 此外, 另外, 加上

**Structure :** …，此外 / 另外，… · …，加上…

此外 = en outre (écrit) ; 另外 = de plus, par ailleurs, ou « autre » (另外一个) ; 加上 = ajouté à cela, en plus (pour une raison supplémentaire).

**Exemples**

- 今天很冷，加上下雨，没有人出去。 *Jīntiān hěn lěng, jiāshang xià yǔ, méiyǒu rén chūqù.* — Il fait froid aujourd'hui, et en plus il pleut : personne ne sort.
- 我买了面包，另外还买了一些水果。 *Wǒ mǎile miànbāo, lìngwài hái mǎile yìxiē shuǐguǒ.* — J'ai acheté du pain et, en plus, quelques fruits.

**Questions** (bonne réponse en gras)

- 这里交通方便，___，房租也不贵。 (Ici, les transports sont pratiques ; de plus, le loyer n'est pas cher.) → **此外** / 于是 / 否则
- 我想看___一本书。 (Je voudrais voir un autre livre.) → **另外** / 此外 / 加上

<sub>Points officiels : conjonctions 此外、另外、加上</sub>

## 23. Puisque : 既然…就

**Structure :** 既然…，就…

既然 = puisque, étant donné que (le fait est connu des deux) ; la conséquence est introduite par 就 : 既然你累了，就休息吧.

**Exemples**

- 既然你不舒服，就别去了。 *Jìrán nǐ bù shūfu, jiù bié qù le.* — Puisque tu ne te sens pas bien, n'y va pas.
- 既然来了，就多住几天吧。 *Jìrán lái le, jiù duō zhù jǐ tiān ba.* — Puisque tu es venu, reste donc quelques jours.

**Questions** (bonne réponse en gras)

- ___你已经决定了，我就不说了。 (Puisque tu as déjà décidé, je ne dis plus rien.) → **既然** / 虽然 / 即使
- 既然大家都同意，我们___开始吧。 (Puisque tout le monde est d'accord, commençons.) → **就** / 才 / 却

<sub>Points officiels : 既然 · 既然……，就……</sub>

## 24. Et même : 甚至

**Structure :** …，甚至…

甚至 = et même, jusqu'à (introduit le cas le plus extrême) : 他很忙，甚至没时间吃饭.

**Exemples**

- 他很忙，甚至没时间吃饭。 *Tā hěn máng, shènzhì méi shíjiān chī fàn.* — Il est très occupé, au point de ne pas avoir le temps de manger.
- 这个问题很简单，甚至孩子都知道。 *Zhège wèntí hěn jiǎndān, shènzhì háizi dōu zhīdào.* — Ce problème est simple, même les enfants le savent.

**Questions** (bonne réponse en gras)

- 他太累了，___站着都能睡着。 (Il est si fatigué qu'il pourrait dormir debout.) → **甚至** / 否则 / 于是
- 这里很多人都会说汉语，___老人也会。 (Beaucoup de gens parlent chinois ici, même les personnes âgées.) → **甚至** / 然而 / 因此

<sub>Points officiels : 甚至 · ……，甚至……</sub>

## 25. Non seulement… mais aussi : 不仅, 不光

**Structure :** 不仅 / 不光…，还 / 而且 / 也…

不仅 (écrit) et 不光 (oral) ont le sens de 不但 : « non seulement…, mais encore… ». La seconde partie commence par 而且, 还 ou 也.

**Exemples**

- 他不仅会唱歌，还会跳舞。 *Tā bùjǐn huì chàng gē, hái huì tiàowǔ.* — Non seulement il chante, mais il danse aussi.
- 不光我喜欢，我的朋友们也都喜欢。 *Bùguāng wǒ xǐhuan, wǒ de péngyoumen yě dōu xǐhuan.* — Il n'y a pas que moi qui aime ça, mes amis aussi.

**Questions** (bonne réponse en gras)

- 这家店的东西不仅便宜，___质量也好。 (Les produits de ce magasin sont non seulement bon marché, mais aussi de bonne qualité.) → **而且** / 却 / 否则
- ___他会说，我也会说。 (Il n'est pas le seul à savoir le dire, moi aussi.) → **不光** / 尽管 / 既然

<sub>Points officiels : 不光、不仅 · 不仅/不光……，还/而且…… ; ……，并且……</sub>

## 26. Si, sinon : 要是, 否则

**Structure :** 要是…，就… · …，否则…

要是 = si (oral, comme 如果). 否则 = sinon, autrement : 快点儿，否则就来不及了.

**Exemples**

- 要是明天不下雨，我们就去爬山。 *Yàoshi míngtiān bú xià yǔ, wǒmen jiù qù pá shān.* — S'il ne pleut pas demain, nous irons faire de la randonnée.
- 快点儿走，否则就来不及了。 *Kuài diǎnr zǒu, fǒuzé jiù láibují le.* — Dépêche-toi, sinon on n'aura pas le temps.

**Questions** (bonne réponse en gras)

- 你要多穿点儿衣服，___会感冒的。 (Mets plus de vêtements, sinon tu vas attraper froid.) → **否则** / 要是 / 于是
- ___你有问题，就给我打电话。 (Si tu as un problème, appelle-moi.) → **要是** / 否则 / 尽管

<sub>Points officiels : 要是 · ……，否则…… ; 要是……，就……</sub>

## 27. Petits mots : 等, 者, 之, 就是说

**Structure :** …等 · verbe + 者 · A 之 B · 就是说

等 à la fin d'une liste = etc. 者 forme des noms de personnes : 作者 (auteur), 读者 (lecteur). 之 est le 的 de la langue écrite : 之一 (l'un de). 就是说 ou 这就是说 = c'est-à-dire. 啊 et 嗯 sont des interjections : 啊 ? (hein ?), 嗯 (oui, hm).

**Exemples**

- 我买了苹果、香蕉等水果。 *Wǒ mǎile píngguǒ, xiāngjiāo děng shuǐguǒ.* — J'ai acheté des pommes, des bananes et d'autres fruits.
- 他是中国最有名的作家之一。 *Tā shì Zhōngguó zuì yǒumíng de zuòjiā zhī yī.* — C'est l'un des écrivains les plus célèbres de Chine.

**Questions** (bonne réponse en gras)

- 这本书的作___是谁？ (Qui est l'auteur de ce livre ?) → **者** / 家 / 员
- 他明天不来，___，我们只有四个人。 (Il ne vient pas demain, c'est-à-dire que nous ne serons que quatre.) → **就是说** / 一般来说 / 就是了

<sub>Points officiels : particules 等2、者、之、就是 · interjections 啊、嗯 · 就是说 / 这就是说</sub>

## 28. Expressions en quatre caractères : 一A一B, 无A无B, 有A有B

**Structure :** 一 + A + 一 + B · 无 + A + 无 + B · 有 + A + 有 + B

Ces moules donnent des expressions figées : 一心一意 (de tout son cœur), 一模一样 (exactement pareil) ; 无忧无虑 (sans souci) ; 有说有笑 (bavarder et rire), 有声有色 (vivant, coloré).

**Exemples**

- 他们俩长得一模一样。 *Tāmen liǎ zhǎng de yìmú-yíyàng.* — Ils se ressemblent comme deux gouttes d'eau.
- 大家有说有笑地走进了教室。 *Dàjiā yǒu shuō yǒu xiào de zǒujìnle jiàoshì.* — Tout le monde est entré en classe en bavardant et en riant.

**Questions** (bonne réponse en gras)

- 孩子们过着___无虑的生活。 (Les enfants mènent une vie sans souci.) → **无忧** / 有忧 / 一忧
- 他___一意地学习汉语。 (Il étudie le chinois de tout son cœur.) → **一心** / 有心 / 无心

<sub>Points officiels : 一A一B · 无A无B · 有A有B</sub>

## 29. Avoir le temps, ne pas manquer : 来得及, 有的是, 不怎么

**Structure :** 来得及 / 来不及 + verbe · 有的是 + nom · 不怎么 + verbe / adjectif

来得及 = avoir encore le temps ; 来不及 = ne plus avoir le temps. 有的是 = il y en a à profusion : 时间有的是. 不怎么 = pas très, pas tellement : 我不怎么喜欢.

**Exemples**

- 别着急，还来得及。 *Bié zháojí, hái láidejí.* — Pas de panique, on a encore le temps.
- 我不怎么喜欢吃辣的。 *Wǒ bù zěnme xǐhuan chī là de.* — Je n'aime pas trop manger épicé.

**Questions** (bonne réponse en gras)

- 电影已经开始了，现在去___了。 (Le film a déjà commencé, c'est trop tard pour y aller.) → **来不及** / 来得及 / 有的是
- 你慢慢做，时间___。 (Prends ton temps, on en a à revendre.) → **有的是** / 来不及 / 不怎么

<sub>Points officiels : 来得及 / 来不及 · 有的是 · 不怎么</sub>

## 30. De jour en jour : 一天比一天

**Structure :** 一 + classificateur + 比 + 一 + classificateur

一天比一天, 一年比一年 = de jour en jour, d'année en année (évolution progressive). On l'emploie avec un adjectif : 天气一天比一天冷.

**Exemples**

- 天气一天比一天冷了。 *Tiānqì yì tiān bǐ yì tiān lěng le.* — Il fait de plus en plus froid de jour en jour.
- 他的汉语一年比一年好。 *Tā de Hànyǔ yì nián bǐ yì nián hǎo.* — Son chinois s'améliore d'année en année.

**Questions** (bonne réponse en gras)

- 孩子一天___一天大了。 (L'enfant grandit de jour en jour.) → **比** / 跟 / 和
- 这里的人一年比一年___。 (Il y a de plus en plus de monde ici, d'année en année.) → **多** / 很多 / 更很多

<sub>Points officiels : 一 + cl. + 比 + 一 + cl.</sub>

## 31. Sur le plan de, prenons l'exemple de

**Structure :** 在…方面 · 拿…来说

在…方面 = sur le plan de, en ce qui concerne : 在学习方面. 拿…来说 = prenons l'exemple de : 拿我来说 (moi, par exemple).

**Exemples**

- 在工作方面，他很有经验。 *Zài gōngzuò fāngmiàn, tā hěn yǒu jīngyàn.* — Sur le plan professionnel, il a beaucoup d'expérience.
- 拿我来说，我每天都运动。 *Ná wǒ lái shuō, wǒ měi tiān dōu yùndòng.* — Moi, par exemple, je fais du sport tous les jours.

**Questions** (bonne réponse en gras)

- 在生活___，他给了我很多帮助。 (Dans la vie quotidienne, il m'a beaucoup aidé.) → **方面** / 方法 / 方向
- ___北京来说，冬天很冷。 (Prenons Pékin : l'hiver y est très froid.) → **拿** / 为了 / 在

<sub>Points officiels : 在……方面 · 拿……来说</sub>

## 32. Bien assez : 够…的

**Structure :** 够 + adjectif + 的

够…的 = vraiment, bien assez (souvent un peu excessif) : 今天够冷的 (il fait sacrément froid).

**Exemples**

- 今天够冷的。 *Jīntiān gòu lěng de.* — Il fait sacrément froid aujourd'hui.
- 你这个人也够奇怪的。 *Nǐ zhège rén yě gòu qíguài de.* — Toi aussi, tu es vraiment bizarre.

**Questions** (bonne réponse en gras)

- 这个工作___累的。 (Ce travail est vraiment fatigant.) → **够** / 能 / 会
- 你说得够清楚___了。 (Tu t'es exprimé assez clairement.) → **的** / 得 / 地

<sub>Points officiels : 够……的</sub>

## 33. Plus jamais, impossible de : 再也不, 怎么也不

**Structure :** 再也 + 不 / 没 + verbe · 怎么 + 都 / 也 + 不 / 没 + verbe

再也不 = plus jamais (à l'avenir) ; 再也没 = plus jamais depuis (au passé). 怎么也不 / 怎么都不 = impossible de, malgré tous les efforts : 怎么也想不起来.

**Exemples**

- 我再也不喝酒了。 *Wǒ zài yě bù hē jiǔ le.* — Je ne boirai plus jamais d'alcool.
- 他的名字我怎么也想不起来。 *Tā de míngzi wǒ zěnme yě xiǎng bu qǐlái.* — Impossible de me rappeler son nom.

**Questions** (bonne réponse en gras)

- 他走了以后，___没回来过。 (Depuis qu'il est parti, il n'est plus jamais revenu.) → **再也** / 再次 / 重新
- 这个问题我___也想不明白。 (Je n'arrive pas du tout à comprendre ce problème.) → **怎么** / 什么 / 为什么

<sub>Points officiels : 再也不/没…… · 怎么都/也 + 不/没……</sub>

## 34. Pour, afin de : 为了…而, …好…

**Structure :** 为了 + but + 而 + verbe · …，好 + but

为了…而… souligne le but d'une action (écrit) : 为了理想而努力. 好 en tête de la seconde partie = pour que, afin de : 你把电话号码给我，好联系你.

**Exemples**

- 我们要为了理想而努力。 *Wǒmen yào wèile lǐxiǎng ér nǔlì.* — Nous devons travailler dur pour notre idéal.
- 你把电话号码给我，我好联系你。 *Nǐ bǎ diànhuà hàomǎ gěi wǒ, wǒ hǎo liánxì nǐ.* — Donne-moi ton numéro, pour que je puisse te contacter.

**Questions** (bonne réponse en gras)

- 他为了学好汉语___来到中国。 (Il est venu en Chine pour bien apprendre le chinois.) → **而** / 却 / 把
- 早点儿睡吧，明天___早起。 (Couche-toi tôt, pour pouvoir te lever tôt demain.) → **好** / 才 / 再

<sub>Points officiels : 为了……而…… · ……，好……</sub>

## 35. Une chose à la fois, rien à dire

**Structure :** 动词 + 一X是一X · （没）有什么（好）X的

动词 + 一X是一X = faire autant qu'on peut, au fur et à mesure : 能做一点是一点. （没）有什么（好）X的 = il n'y a rien de… à… : 有什么好说的 ? (qu'y a-t-il à dire ?), 没什么好担心的 (rien à craindre).

**Exemples**

- 时间不多了，能做一点是一点。 *Shíjiān bù duō le, néng zuò yìdiǎn shì yìdiǎn.* — Il ne reste plus beaucoup de temps, faisons ce qu'on peut.
- 这有什么好担心的？ *Zhè yǒu shénme hǎo dānxīn de?* — Qu'y a-t-il d'inquiétant là-dedans ?

**Questions** (bonne réponse en gras)

- 这个电影没什么好___的。 (Ce film ne vaut pas la peine d'être vu.) → **看** / 看看看 / 好看
- 能学一点___一点。 (Apprenons ce qu'on peut, petit à petit.) → **是** / 就 / 才

<sub>Points officiels : 动词 + 一X是一X · （没）有什么（好）X的</sub>

## 36. C'est vrai que… mais : X是X

**Structure :** X是X · X是X，Y是Y

X是X reconnaît un fait avant une réserve : 好是好，可是太贵 (c'est bien, mais trop cher). X是X，Y是Y sépare deux choses à ne pas confondre : 朋友是朋友，工作是工作 (l'amitié est une chose, le travail en est une autre).

**Exemples**

- 朋友是朋友，工作是工作。 *Péngyou shì péngyou, gōngzuò shì gōngzuò.* — L'amitié est une chose, le travail en est une autre.
- 这个菜好吃是好吃，就是有点儿辣。 *Zhège cài hǎochī shì hǎochī, jiùshì yǒudiǎnr là.* — Ce plat est bon, c'est vrai, mais un peu épicé.

**Questions** (bonne réponse en gras)

- 他聪明___聪明，就是不努力。 (Il est intelligent, c'est vrai, mais il ne travaille pas.) → **是** / 就 / 也
- 你是你，我___我。 (Toi, c'est toi ; moi, c'est moi.) → **是** / 就 / 也

<sub>Points officiels : X是X · X是X，Y是Y</sub>

## 37. Que tu le veuilles ou non : 也得, 说什么也得

**Structure :** X也得X，不X也得X · 说什么 / 怎么也得 + verbe · 让 / 叫你X你就X

X也得X，不X也得X = qu'on le veuille ou non, il faut le faire : 去也得去，不去也得去. 说什么也得… = coûte que coûte. 让你X你就X = fais ce qu'on te dit : 让你去你就去.

**Exemples**

- 这个会很重要，你去也得去，不去也得去。 *Zhège huì hěn zhòngyào, nǐ qù yě děi qù, bú qù yě děi qù.* — Cette réunion est très importante : que tu le veuilles ou non, tu dois y aller.
- 妈妈让你吃你就吃吧。 *Māma ràng nǐ chī nǐ jiù chī ba.* — Maman te dit de manger, alors mange.

**Questions** (bonne réponse en gras)

- 今天说什么___得把工作做完。 (Aujourd'hui, coûte que coûte, je dois finir le travail.) → **也** / 就 / 才
- 老师叫你回答你___回答吧。 (Le professeur te demande de répondre, alors réponds.) → **就** / 也 / 才

<sub>Points officiels : X也得X，不X也得X · 说什么/怎么（着）也得X · 让/叫你X你就X</sub>

## 38. Il suffit de, laisse faire : 就是了, 就X吧

**Structure :** X就是了 · X就X（点儿）吧 · 你X你的吧 · 还X呢

X就是了 = il suffit de, pas de souci : 你放心就是了. X就X吧 = tant pis, acceptons : 贵就贵点儿吧. 你X你的吧 = continue, ne t'occupe pas de moi : 你忙你的吧. 还X呢 se moque d'un décalage : 还大学生呢 ! (et ça se dit étudiant !).

**Exemples**

- 你放心就是了。 *Nǐ fàngxīn jiù shì le.* — Ne t'inquiète pas, c'est tout.
- 贵就贵点儿吧，我喜欢。 *Guì jiù guì diǎnr ba, wǒ xǐhuan.* — Tant pis si c'est un peu cher, ça me plaît.

**Questions** (bonne réponse en gras)

- 我自己来，你忙你___吧。 (Je m'en occupe, continue ce que tu faisais.) → **的** / 了 / 得
- 这么简单的题都不会，还大学生___！ (Même pas capable de répondre à une question si simple, et ça se dit étudiant !) → **呢** / 吗 / 吧

<sub>Points officiels : X就是了 · X就X（点儿）吧 · 你X你的吧 · 还X呢</sub>

## 39. Ne pas pouvoir : 吃不了, 去得了

**Structure :** verbe + 得了 / 不了

Verbe + 得了 (de liǎo) / 不了 (bu liǎo) dit si l'action est possible : 这么多菜我吃不了 (je ne peux pas tout manger), 明天你去得了吗 ? (tu pourras y aller demain ?).

**Exemples**

- 这么多菜，我一个人吃不了。 *Zhème duō cài, wǒ yí gè rén chī bu liǎo.* — Autant de plats, je ne peux pas tout manger seul.
- 明天下雨，你去得了吗？ *Míngtiān xià yǔ, nǐ qù de liǎo ma?* — S'il pleut demain, tu pourras y aller ?

**Questions** (bonne réponse en gras)

- 我的腿疼，走不___了。 (J'ai mal à la jambe, je ne peux plus marcher.) → **了** / 过 / 着
- 这件事你做得___吗？ (Tu peux t'en charger ?) → **了** / 着 / 过

<sub>Points officiels : complément potentiel 2 (得了 / 不了)</sub>

## 40. 把 : nouvelles constructions

**Structure :** 把 + objet + verbe redoublé · 把 + objet + verbe + 了 · 把 + objet + verbe + fois / durée · 把 + objet + adverbe + verbe

Au niveau 4, 把 s'emploie aussi avec un verbe redoublé (把房间打扫打扫), avec 了 seul (把药吃了), avec un nombre de fois ou une durée (把课文读了三遍), ou avec un adverbe devant le verbe (把书一放就走了).

**Exemples**

- 你把房间打扫打扫吧。 *Nǐ bǎ fángjiān dǎsǎo dǎsǎo ba.* — Fais donc un peu le ménage dans ta chambre.
- 我把课文读了三遍。 *Wǒ bǎ kèwén dúle sān biàn.* — J'ai lu le texte trois fois.

**Questions** (bonne réponse en gras)

- 快把药吃___！ (Prends vite tes médicaments !) → **了** / 着 / 过
- 你把这个问题再想___吧。 (Réfléchis encore un peu à cette question.) → **一想** / 想想想 / 一想想

<sub>Points officiels : phrases en 把 2</sub>

## 41. Le passif oral : 叫, 让

**Structure :** sujet + 叫 / 让 + auteur + verbe + complément

À l'oral, 叫 et 让 remplacent 被 pour le passif, mais l'auteur doit alors être nommé : 我的自行车叫人骑走了.

**Exemples**

- 我的自行车叫人骑走了。 *Wǒ de zìxíngchē jiào rén qízǒu le.* — On m'a pris mon vélo.
- 蛋糕让弟弟吃完了。 *Dàngāo ràng dìdi chīwán le.* — Le gâteau a été fini par mon petit frère.

**Questions** (bonne réponse en gras)

- 我的蛋糕___弟弟吃了。 (Mon gâteau a été mangé par mon petit frère.) → **让** / 把 / 对
- 我的钱包叫___拿走了。 (Quelqu'un a pris mon portefeuille.) → **别人** / 的别人 / 别人的

<sub>Points officiels : prépositions 将、由2、叫、让 · passif 2 (叫 / 让)</sub>

## 42. Faire faire, choisir comme : 使, 选…当

**Structure :** 表扬 / 批评 + personne + verbe · 选 / 收 + personne + 当 / 做 + rôle · 使 / 让 + personne + verbe

Certains verbes ont un objet qui fait aussi l'action suivante : 老师表扬他学习努力 (le professeur l'a félicité pour ses efforts). 选 / 收 + personne + 当 / 做 + rôle = choisir ou prendre quelqu'un comme… : 大家选他当班长. 使 / 让 + personne + verbe = rendre, causer : 这件事使我很难过.

**Exemples**

- 大家选他当班长。 *Dàjiā xuǎn tā dāng bānzhǎng.* — Tout le monde l'a choisi comme chef de classe.
- 这个消息使我很高兴。 *Zhège xiāoxi shǐ wǒ hěn gāoxìng.* — Cette nouvelle m'a rendu très content.

**Questions** (bonne réponse en gras)

- 他的话___大家都笑了。 (Ses paroles ont fait rire tout le monde.) → **使** / 把 / 被
- 老师___他学习认真。 (Le professeur l'a félicité pour son sérieux.) → **表扬** / 把 / 选

<sub>Points officiels : phrase pivot 2</sub>

## 43. Ne pas valoir, comparé à : 不如, 跟…相比

**Structure :** A 不如 B (+ adjectif) · 跟…相比

A 不如 B = A ne vaut pas B, A est moins… que B : 我的汉语不如他好. 跟…相比 = comparé à, par rapport à : 跟去年相比.

**Exemples**

- 坐公共汽车不如坐地铁快。 *Zuò gōnggòng qìchē bùrú zuò dìtiě kuài.* — Le bus est moins rapide que le métro.
- 跟去年相比，今年冷多了。 *Gēn qùnián xiāngbǐ, jīnnián lěng duō le.* — Comparé à l'an dernier, il fait bien plus froid cette année.

**Questions** (bonne réponse en gras)

- 我唱歌___他唱得好。 (Je chante moins bien que lui.) → **不如** / 比不 / 不是
- 跟北京___，这里的冬天不太冷。 (Comparé à Pékin, l'hiver ici n'est pas très froid.) → **相比** / 比较 / 相对

<sub>Points officiels : comparaison 3 (不如, 跟……相比)</sub>

## 44. Double négation

**Structure :** 不能不 · 没有…不… · 不得不

Deux négations s'annulent et renforcent : 不能不去 (on ne peut pas ne pas y aller = il faut y aller), 没有人不喜欢他 (tout le monde l'aime), 不得不 (être obligé de).

**Exemples**

- 这件事我不能不管。 *Zhè jiàn shì wǒ bù néng bù guǎn.* — Je ne peux pas ne pas m'occuper de cette affaire.
- 我们班没有人不喜欢她。 *Wǒmen bān méiyǒu rén bù xǐhuan tā.* — Dans notre classe, tout le monde l'aime.

**Questions** (bonne réponse en gras)

- 车坏了，我不___不走路去。 (La voiture est en panne, j'ai été obligé d'y aller à pied.) → **得** / 是 / 了
- 他的话没有人不___。 (Tout le monde croit ce qu'il dit.) → **相信** / 不相信 / 没相信

<sub>Points officiels : double négation</sub>

## 45. Non pas… mais, soit… soit : 不是…而是, 不是…就是

**Structure :** 不是…，而是… · 不是…，就是…

不是 A，而是 B = ce n'est pas A, c'est B (rectification). 不是 A，就是 B = soit A, soit B (une des deux possibilités, souvent pour une habitude).

**Exemples**

- 他不是不想来，而是没有时间。 *Tā bú shì bù xiǎng lái, ér shì méiyǒu shíjiān.* — Ce n'est pas qu'il ne veut pas venir, c'est qu'il n'a pas le temps.
- 他周末不是看书，就是看电影。 *Tā zhōumò bú shì kàn shū, jiù shì kàn diànyǐng.* — Le week-end, soit il lit, soit il regarde un film.

**Questions** (bonne réponse en gras)

- 这不是我的错，___你的错。 (Ce n'est pas ma faute, c'est la tienne.) → **而是** / 于是 / 还是
- 这几天不是刮风，___下雨。 (Ces jours-ci, soit il y a du vent, soit il pleut.) → **就是** / 但是 / 于是

<sub>Points officiels : 不是……，而是…… · 不是……，就是……</sub>

## 46. À la fois, d'un côté… de l'autre

**Structure :** 既…，又 / 也… · 一方面…，另一方面…

既…又… = à la fois… et… (plus écrit que 又…又…). 一方面…，另一方面… = d'un côté…, de l'autre… (deux aspects ou deux raisons).

**Exemples**

- 这个办法既简单又方便。 *Zhège bànfǎ jì jiǎndān yòu fāngbiàn.* — Cette méthode est à la fois simple et pratique.
- 我来中国，一方面是学习汉语，另一方面是了解中国文化。 *Wǒ lái Zhōngguó, yì fāngmiàn shì xuéxí Hànyǔ, lìng yì fāngmiàn shì liǎojiě Zhōngguó wénhuà.* — Je suis venu en Chine, d'une part pour apprendre le chinois, d'autre part pour connaître la culture chinoise.

**Questions** (bonne réponse en gras)

- 她既会唱歌，___会跳舞。 (Elle sait à la fois chanter et danser.) → **也** / 而 / 却
- 一方面我很想去，___方面我又没有时间。 (D'un côté j'ai très envie d'y aller, de l'autre je n'ai pas le temps.) → **另一** / 一 / 这

<sub>Points officiels : 既……，又/也…… ; 一方面……，另一方面……</sub>

## 47. D'abord, ensuite, alors : 首先, 其次, 于是

**Structure :** 首先…，其次 / 然后… · …，于是…

首先…，其次… = premièrement…, deuxièmement… ; 首先…，然后… = d'abord…, ensuite…. 于是 = alors, c'est ainsi que (conséquence dans un récit).

**Exemples**

- 首先，我要谢谢大家。 *Shǒuxiān, wǒ yào xièxie dàjiā.* — Tout d'abord, je tiens à remercier tout le monde.
- 太晚了，于是我们回家了。 *Tài wǎn le, yúshì wǒmen huí jiā le.* — Il était trop tard, alors nous sommes rentrés.

**Questions** (bonne réponse en gras)

- 首先要了解问题，___要想办法解决。 (D'abord comprendre le problème, ensuite chercher comment le résoudre.) → **其次** / 于是 / 否则
- 他很想学汉语，___来到了中国。 (Il voulait vraiment apprendre le chinois, c'est ainsi qu'il est venu en Chine.) → **于是** / 其次 / 首先

<sub>Points officiels : 首先……，其次/然后…… ; ……，于是……</sub>

## 48. Même : 连…也 / 都

**Structure :** 连 + élément + 也 / 都 + verbe

连…也 / 都… = même… : 连孩子都知道 (même les enfants le savent). L'élément mis en avant est le cas le plus inattendu ; la suite est souvent négative : 他忙得连饭都没吃.

**Exemples**

- 这个问题连孩子都知道。 *Zhège wèntí lián háizi dōu zhīdào.* — Même les enfants connaissent la réponse.
- 他忙得连饭都没吃。 *Tā máng de lián fàn dōu méi chī.* — Il était si occupé qu'il n'a même pas mangé.

**Questions** (bonne réponse en gras)

- 我___他的名字都不知道。 (Je ne connais même pas son nom.) → **连** / 把 / 对
- 连老师___不会这道题。 (Même le professeur ne sait pas résoudre cet exercice.) → **也** / 就 / 才

<sub>Points officiels : 连……也/都……</sub>

## 49. Bien que : 尽管…但是

**Structure :** 尽管…，但是 / 可是 / 还是…

尽管 = bien que, malgré le fait que (plus fort que 虽然) ; la seconde partie commence par 但是, 可是 ou 还是.

**Exemples**

- 尽管下着大雨，他还是来了。 *Jǐnguǎn xiàzhe dà yǔ, tā háishi lái le.* — Malgré la forte pluie, il est quand même venu.
- 尽管很累，但是我很高兴。 *Jǐnguǎn hěn lèi, dànshì wǒ hěn gāoxìng.* — Bien que très fatigué, je suis content.

**Questions** (bonne réponse en gras)

- ___他很努力，可是成绩还是不好。 (Bien qu'il travaille dur, ses notes restent mauvaises.) → **尽管** / 不管 / 既然
- 尽管他说了很多次，我___不明白。 (Il me l'a dit plusieurs fois, mais je ne comprends toujours pas.) → **还是** / 就是 / 于是

<sub>Points officiels : 尽管……，但是/可是…… ; ……，然而…… ; ……，不过…… ; ……X是X，就是/不过……</sub>

## 50. Quel que soit : 不管, 无论

**Structure :** 不管 / 无论 + question + 都 / 也…

不管 (oral) et 无论 (écrit) = quel que soit, peu importe. Ils sont suivis d'une forme de question (mot interrogatif, choix 还是, ou 去不去) et la suite contient 都 ou 也.

**Exemples**

- 不管天气怎么样，他都去跑步。 *Bùguǎn tiānqì zěnmeyàng, tā dōu qù pǎobù.* — Quel que soit le temps, il va courir.
- 无论你去不去，我都要去。 *Wúlùn nǐ qù bu qù, wǒ dōu yào qù.* — Que tu y ailles ou non, moi j'y vais.

**Questions** (bonne réponse en gras)

- 不管多忙，他___每天给妈妈打电话。 (Aussi occupé soit-il, il appelle sa mère tous les jours.) → **都** / 就 / 才
- ___遇到什么问题，你都可以找我。 (Quel que soit le problème, tu peux venir me voir.) → **无论** / 尽管 / 既然

<sub>Points officiels : 不管/无论……，都/也……</sub>

## 51. Même si : 即使, 就是…也

**Structure :** 即使 / 就是…，也…

即使…也… = même si… (hypothèse), écrit ou soutenu ; à l'oral, 就是…也… a le même sens.

**Exemples**

- 即使明天下雨，我们也要去。 *Jíshǐ míngtiān xià yǔ, wǒmen yě yào qù.* — Même s'il pleut demain, nous irons.
- 就是再忙，你也要吃饭。 *Jiùshì zài máng, nǐ yě yào chī fàn.* — Même si tu es très occupé, il faut manger.

**Questions** (bonne réponse en gras)

- 即使你不说，我___知道。 (Même si tu ne le dis pas, je le sais.) → **也** / 就 / 都是
- ___失败了，也没关系。 (Même si on échoue, ce n'est pas grave.) → **即使** / 既然 / 因此

<sub>Points officiels : 即使/就是……，也……</sub>

## 52. Phrases contractées : 不…也…

**Structure :** proposition + proposition sans mot de liaison · 不…也…

À l'oral, deux propositions peuvent se suivre sans mot de liaison : 你不去我去 (si tu n'y vas pas, j'y vais). 不 A 也 B = même sans A, B : 不说也知道 (on le sait sans qu'on le dise).

**Exemples**

- 你不去我去。 *Nǐ bú qù wǒ qù.* — Si tu n'y vas pas, moi j'y vais.
- 这个问题不问也知道。 *Zhège wèntí bú wèn yě zhīdào.* — Pas besoin de demander, on connaît la réponse.

**Questions** (bonne réponse en gras)

- 你不说我___知道。 (Même si tu ne le dis pas, je le sais.) → **也** / 就 / 还
- 不吃___不饿。 (Même sans manger, je n'ai pas faim.) → **也** / 就 / 才

<sub>Points officiels : phrases complexes contractées (sans marque, 不……也……)</sub>

## 53. Environ : 来, 大约, 左右, 前后

**Structure :** nombre rond + 来 + classificateur · 大约 + nombre · nombre + 左右 · moment + 前后

来 après un nombre rond = environ, un peu plus ou un peu moins : 十来个人, 二十来岁. 大约 = environ (devant le nombre) ; 左右 = environ (après le nombre) ; 前后 = aux alentours de (une date ou un moment) : 春节前后.

**Exemples**

- 教室里有二十来个学生。 *Jiàoshì li yǒu èrshí lái gè xuésheng.* — Il y a une vingtaine d'élèves dans la salle.
- 我大约八点到。 *Wǒ dàyuē bā diǎn dào.* — J'arriverai vers huit heures.

**Questions** (bonne réponse en gras)

- 他看起来三十岁___。 (Il a l'air d'avoir dans les trente ans.) → **左右** / 来 / 大约
- 新年___，火车票很难买。 (Autour du Nouvel An, les billets de train sont difficiles à obtenir.) → **前后** / 左右 / 大约

<sub>Points officiels : approximations 3 (来, 大约, 左右, 前后)</sub>

## 54. Décimales, fractions, pourcentages, multiples

**Structure :** 点 · 分之 · 百分之 · 倍

Les décimales se lisent avec 点 : 3.5 = 三点五. Les fractions s'énoncent dénominateur d'abord : 三分之一 (1/3). Les pourcentages : 百分之五十 (50 %). Les multiples : 倍 : 两倍 (deux fois plus), A 是 B 的两倍.

**Exemples**

- 我们班百分之八十的学生是女生。 *Wǒmen bān bǎi fēn zhī bāshí de xuésheng shì nǚshēng.* — Dans notre classe, 80 % des élèves sont des filles.
- 今年的学生是去年的两倍。 *Jīnnián de xuésheng shì qùnián de liǎng bèi.* — Il y a deux fois plus d'élèves cette année que l'an dernier.

**Questions** (bonne réponse en gras)

- 三___之一的人没来。 (Un tiers des gens ne sont pas venus.) → **分** / 倍 / 点
- 这个东西的价格高了一___。 (Le prix de cet article a doublé.) → **倍** / 分 / 点
